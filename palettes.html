Palettes and color

The palette (at the top of Tool settings) stores the drawing colors and the generation colors; each color carries parameters that tell generators how to use it.

Where the palette is

There is no separate Palettes window any more. The drawing palette is shown at the top of the Tool settings window (the View > Tool settings window), above the parameters of the active tool.

  • Swatches - a click selects a color; a second click or a right-click opens editing (Color Picker). The tooltip: "click to select, click again to edit, right-click to edit". When the palette has more colors than fit, < and > buttons with a "page / pages" counter switch between pages.
  • Current color - after a color is picked from the canvas an editor with the current color is shown above the swatches.
  • Add random color adds a random color, Remove color removes the selected one.
  • The picker button in the color editor (Pick color from canvas) takes a color directly from the canvas.
  • The generation colors are a separate set, edited under the Fill section of the paint parameters: Generation colors is the set of colors from which the generator picks at random; Add color to generation set adds a color, and the "Random color from set" color can be replaced with a fixed one.

Color parameters: Body and Outline

Each pencil color contains settings for two pixel roles, Body and Outline. In the interface they appear as two collapsible sections of Tool settings - Fill (the body) and Outline:

  • Active - whether the role takes part in generation.
  • Chance (Body chance, Outline chance) - the probability, 0-100%, that a pixel is used by the generator. The main shape is made reliable (100%), highlights, drops and sparks less likely.
  • AutoColor - the color is picked from the palette automatically.
  • Generation colors / Fill color - a separate set of colors for generation; it does not overwrite the drawing color.

Connect these parameters through the Advanced paint settings of the pencil and fill.

Palette management

The Palette options button next to the swatches (tooltip: "Open, import, save, and manage palettes") opens a popup:

  • Choose palette from folder... - a list of the saved palettes; choosing one applies it.
  • Import palette - load a palette from a file (PNG, HEX, GPL, JSON).
  • Save palette - asks for a Name and saves the current palette as a new file.
  • Refresh palette list - re-read the palette folder.
  • Open settings folder - open the settings folder.

Palette formats

FormatDescription
PNGUnique visible colors are read left to right, top to bottom; fully transparent pixels are skipped.
HEXOne RRGGBB or RRGGBBAA color per line, # is optional.
GPLThe standard GIMP Palette header, rows with decimal RGB.
JSONname, colors (RGBA 0-1, Unity objects) and an optional tools with per-color parameters.

A palette contains 1 to 256 colors; the file is at most 16 MiB. Import palette copies the palette as normalized JSON to the Settings/Palettes folder and applies it. Save palette creates a new file (with Body/Outline parameters); existing files are never overwritten. Refresh palette list finds files added manually. Importing changes the swatches and selects the first one; painted pixels remain. Undo restores the previous palette.

Palette tools

The Filter > Palette tools menu opens a window with tabs:

  • Ramps - builds a ramp of shades from shadow to highlight from a Base color: Ramp steps, Shadow depth, Highlight lift, Hue shift (degrees) and Saturation shift. The "Cool shadows, warm highlights" mode makes shadows cooler and highlights warmer. Add ramp to pencil palette adds the colors to the palette.
  • Hue shift - shifts Hue (degrees), Saturation, Brightness. The scope (Apply to): the active layer and frame, the active layer in all frames, the active frame on all layers, or the whole animation. Locked layers are skipped.
  • Replace colors - replacing a Single color, Ramp to ramp or Palette to palette (colors are matched by position).
  • Indexed - converting the document to indexed mode (Convert to indexed, Detect palette from artwork): every pixel is bound to a palette slot, so the whole animation changes palette in one action.
  • Palette swap - switching the palette of an indexed document (Swap).

Replacing a color across the document

Edit > Replace color in document replaces the chosen color in all layers and frames ("Replace in every layer and frame").
