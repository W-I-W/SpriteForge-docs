Палитры и цвет

Окно Palettes хранит цвета рисования и цвета генерации; каждый цвет несёт параметры того, как генераторы должны его использовать.

Окно Palettes

  • Клик по цвету выбирает его, повторный клик или ПКМ открывает редактирование (Color Picker). Подсказка: «click to select, click again to edit, right-click to edit».
  • Add random color добавляет случайный цвет, Remove color удаляет выбранный.
  • Кнопка пипетки (Pick color from canvas) берёт цвет прямо с холста.
  • Палитры рисования и генерации раздельны. Generation colors - набор цветов, из которых генератор выбирает случайно; Add color to generation set добавляет цвет, а цвет «Random color from set» можно заменить фиксированным.

Параметры цвета: Body и Outline

Каждый цвет карандаша содержит настройки для двух ролей пикселя: Body (тело) и Outline (контур):

  • Active - участвует ли роль в генерации.
  • Chance (Body chance, Outline chance) - вероятность 0-100%, что пиксель будет использован генератором. Основную форму делают надёжной (100%), блики, капли и искры - менее вероятными.
  • AutoColor - цвет подбирается из палитры автоматически.
  • Generation colors / Fill color - собственный набор цветов для генерации; не перезаписывает цвет рисования.

Подключите эти параметры через Advanced paint settings карандаша и заливки.

Управление палитрами

Кнопки управления списком палитр (Properties и окно Palettes):

  • Add random color и Remove color - добавить случайный цвет и удалить выбранный.
  • Import palette - загрузить палитру из файла (PNG, HEX, GPL, JSON).
  • Save palette - сохранить текущую палитру в файл.
  • Refresh palette list - перечитать папку палитр.
  • Open settings folder - открыть папку настроек.
  • Palette options - меню действий над палитрой.

Форматы палитр

ФорматОписание
PNGЧитаются уникальные видимые цвета слева направо, сверху вниз; полностью прозрачные пиксели пропускаются.
HEXОдин цвет RRGGBB или RRGGBBAA на строку, # необязателен.
GPLСтандартный заголовок GIMP Palette, строки с десятичными RGB.
JSONname, colors (RGBA 0-1, объекты Unity) и необязательный tools с параметрами по цветам.

Палитра содержит от 1 до 256 цветов; файл не больше 16 МиБ. Import palette копирует палитру в виде нормализованного JSON в папку Settings/Palettes и применяет её. Save palette создаёт новый файл (с параметрами Body/Outline); существующие файлы не перезаписываются. Refresh palette list находит файлы, добавленные вручную. Импорт меняет цвета и выбирает первый; нарисованные пиксели остаются. Undo восстанавливает прежнюю палитру.

Palette tools

Меню Filter > Palette tools открывает окно с вкладками:

  • Ramps - строит рампу оттенков от тени к свету по Base color: Ramp steps, Shadow depth, Highlight lift, Hue shift (degrees) и Saturation shift. Режим «Cool shadows, warm highlights» делает тени холоднее, света теплее. Add ramp to pencil palette добавляет цвета в палитру.
  • Hue shift - смещение Hue (degrees), Saturation, Brightness. Область применения (Apply to): активные слой и кадр, активный слой во всех кадрах, активный кадр на всех слоях или вся анимация. Заблокированные слои пропускаются.
  • Replace colors - замена Single color, Ramp to ramp или Palette to palette (цвета сопоставляются по позиции).
  • Indexed - преобразование документа в индексированный режим (Convert to indexed, Detect palette from artwork): каждый пиксель привязан к слоту палитры, поэтому вся анимация меняет палитру одним действием.
  • Palette swap - переключение палитры у индексированного документа (Swap).

Замена цвета во всём документе

Edit > Replace color in document заменяет выбранный цвет во всех слоях и кадрах («Replace in every layer and frame»).
