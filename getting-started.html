Getting started

From an empty canvas to a finished PNG or GIF. If you prefer to learn in place, start the Quick tour from the Help menu.

1. Create a document

Open File > New document. Enter a name, choose the width and height (32 x 32 by default) or press a common-size button, then press Create document. An estimated memory figure is shown under the fields; if the size is too large the program reports an error.

On an empty canvas the last 12 opened or saved projects are available.

2. Draw a base

  • B - pencil, E - eraser, G - fill, I - color picker.
  • Colors are chosen at the top of the Tool settings window (the palette swatches). For each color you can set the body (Body) and outline (Outline) parameters and the chance that a generator uses them.
  • Turn on Mirror if you are drawing a symmetric object.
  • Mouse wheel - zoom, Ctrl+wheel - brush size.

Details: Tools.

3. Generate

By default the generator works in the Drawing mode: it creates variations of your drawing. The other generators are add-ons: open the settings window of a generator (View > Drawing submenu) and turn on its Apply ... to Drawing checkbox (Effects, Furniture, UI, Character). Set the number of results and press the magic wand button (Generate) in the tab bar of the Sprites window: the results appear in that window.

  • Keep in library - save the result together with its settings.
  • Add to layer - add the sprite to a new layer of the current frame.
  • Insert the sprite as a new frame of the active layer, or insert all frames of an animation.
  • Create variations - create related variations of the selected sprite.

4. Refine

The result is ordinary pixels on a layer. Fix them with the tools, add an outline (Filter > Outline filter), change the palette (Filters), and create frames in the Timeline.

5. Save and export

  • Ctrl+S - save the project in the .sf format (layers, frames, animations and palettes are saved in full).
  • File > Export... - PNG, sprite sheet, GIF, CSS, .aseprite or an engine atlas. See Export.

Saving a PNG or JPEG does not count as saving the project: the changes stay unsaved, and the recovery copy is kept until you save the .sf.

First minutes: tips

  • Hover over an element - almost everything has a tooltip.
  • Ctrl+click on a slider lets you type an exact value. If a value differs from its default, a reset arrow appears next to it.
  • The F key fits the canvas to the window. Ctrl+Z / Ctrl+Y - undo and redo.
  • F1 opens this documentation.
  • Interface too small: Ctrl++ / Ctrl+- change the scale, Ctrl+Shift+0 picks it automatically.
