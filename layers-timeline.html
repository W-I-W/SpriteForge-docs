Layers and Timeline

The Timeline window combines layers, frames, animation tags and playback. The maximum is 120 frames per document.

Layers

  • + Layer / Add layer adds a layer. Drag a layer by its name to change the order.
  • The Show / hide layer icons (, the eye) and Lock layer (, the padlock): hidden and locked layers are not drawn on by tools and are not changed by filters.
  • A click on a layer name (a double click) opens its parameters:
    • Opacity and Blend mode: Normal, Multiply, Screen, Add. They affect the canvas and the export.
    • Chance - the probability that the layer is used by the generator.
    • Layer group - create/assign a group, rename it, Group visible, Group locked, Remove layer group (the layers stay). Groups are flat.
    • Alpha mask layer - a mask from the alpha channel of another layer in the same frame, with Invert mask. Hide the source layer if it is needed only as a mask. Masks are not evaluated recursively.
  • Groups and masks survive layer reordering, Undo and saving to .sf; old files open as before.
  • Delete layer removes the layer (Delete removes the selected frame or layer).

Frames

  • + Frame / Add frame (Insert) adds an empty frame, Duplicate frame (Ctrl+Insert) duplicates it.
  • Delete frame / Backspace - delete the current frame; Delete - the selected frames.
  • Selecting frames: Ctrl+click - several, Shift+click - a range, Ctrl+A - all.
  • Copy frames with Ctrl+C and paste after the current one with Ctrl+V. The limit is 120 frames.
  • Drag a frame number to reorder: onto the left or right edge of another frame (insert before/after), onto the colored tag bar (to the start or end of the range). Alt on release inserts without a tag; the Untagged zone moves the frame outside all tags.
  • The duration of each frame: Frame duration (ms, 0 = FPS). A value of 0 uses the common FPS.

Animation tags

Colored bars with animation names are shown above the layers (idle, walk, attack, run, jump, hurt, death, roll, cast or your own name).

  • Create: select a range of a layer's frames and right-click → Add tag, or press Ctrl+Shift+T, or enter a name and a range in the Animation and onion settings window (Create animation).
  • A click on a bar selects the range and its first frame; Play plays the selected animation. Overlapping ranges are placed in separate rows.
  • A click on a colored tag opens its parameters: name, range, loop (Loop), the layer set (Layers in this tag), deletion (Delete tag).
  • A layer can be dragged by its name onto a tag to include it in the set; the set is stored in the project.
  • Frame cells take the color of their set. If the last frame is taken out, the empty tag is removed; inserting without a tag inside a range splits it into two bars with the same name.

Animation and frame parameters

  • The Settings button in the Timeline opens compact parameters: Frame duration (ms, 0 = FPS) of the current frame, Animation name (renaming the selected animation), Delete animation, onion skin and the ImPlot chart.
  • The list on the left lets you show All frames or the frames of a particular animation; the + Animation item creates a new tag.
  • The Play from / Play through dropdowns and the Loop checkbox define playback of the range.
  • An animation name cannot be empty ("Enter an animation name"); without a selected animation rename is unavailable ("Select an animation to rename it").

Playback

  • Space - play/stop (when the Timeline has focus); the buttons First frame (Home), Previous (←), Next (→), Last frame (End).
  • Frames per second - the common FPS. Play from / Play through, Play once, Loop range - range modes.
  • The "Previous 60 frames" / "Next 60 frames" buttons page through the timeline (Frames N-M / total).
  • The Frame timing chart (ImPlot) shows the duration of every frame if built with UIMGUI_ENABLE_IMPLOT.

Onion skin

Shows up to 4 previous and up to 4 next frames translucently (Previous onion frames, Next onion frames, Onion opacity). In the preview window the tooltip reads: "Frame preview (onion skin): previous and next frames".

Inbetween: intermediate frames

Ctrl+I opens the Inbetween modes for two selected frames (Ctrl+click):

  • Midpoint - move the sprite to the middle without stretching.
  • Motion stretch - draw a slightly elongated intermediate pose.
  • Full motion trail - draw the path from the first frame to the second.
  • The modes can be chosen for the diagonal, horizontal and vertical directions.

The new frame is added after the first of the two; the program reports: "Intermediate frame (mode) added after frame N".

Importing a sprite sheet

File > Import sprite sheet opens an image preview with the parameters: Cell width / height, Horizontal / Vertical margin, Horizontal / Vertical spacing, Columns (0 = auto), Rows (0 = auto), Frame limit (0 = all), FPS. Cells are read left to right and top to bottom into a new unsaved document with an animation. The Import frames button creates the document.
