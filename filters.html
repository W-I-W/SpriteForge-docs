Filters and color editing

The Filter menu applies operations to the active layer and frame unless stated otherwise. All filters can be undone (Undo).

Outline filter

Adds an outline around the drawn shape.

  • Outline thickness - the outline thickness.
  • Include diagonal pixels - take diagonal neighbors into account.
  • Apply outline applies the filter. The outline is clipped at the canvas edges ("Outline is clipped at canvas edges").

Color limit

Limits the number of distinct colors of the active layer and frame while preserving transparency. The Maximum colors parameter sets the limit; if the image already uses that many colors or fewer, the program says so. After applying, the result is shown ("Reduced colors from N to M").

Color indexing

Maps the active layer and frame to the nearest colors of the chosen palette (Palette for indexing). Add colors to the palette first. Result: "Indexed N pixels to M colors".

Inversion

Inverts colors. You can choose which channels to invert (Red / Green / Blue channel). The Apply inversion button; after applying: "Color inversion applied".

Saturation and Gamma

The Saturation settings and Gamma settings dialogs change the saturation and gamma of the active layer and frame. The applied action is noted in the status bar.

Palette tools

Ramps, Hue shift, Replace colors, Indexed and Palette swap are described on the Palettes page.

Replacing a color

Edit > Replace color in document - replace the chosen color in all layers and frames at once.

Filters work on the pixels of the active layer. To apply an effect to the whole frame, merge the needed layers first or use Palette tools with the "Whole animation" scope.
