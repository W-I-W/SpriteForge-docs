Furniture and effects

Two generators with libraries of ready-made types: interior objects and visual effects/materials.

Furniture

The Furniture mode opens the Furniture settings window. Choose a Furniture type and adjust the shape. The Apply furniture to Drawing checkbox at the top of the window turns on the furniture generator instead of the plain variations of the drawing. The Reset furniture settings button restores the defaults.

  • Colors are taken from the palette, like the other generators.
  • The game view (for example Top down or Platformer) affects the projection of the objects.
  • Internally the furniture packs return data "bottom-up", and a common conversion method brings the result to the standard orientation - you never need to flip the result manually.

Effects

The Effects mode and the Effect settings window. Effects are organized into packs (Effect pack); a particular effect is chosen inside a pack. The Apply effects to Drawing checkbox at the top of the window runs generation of the whole effect pack from the drawing on the canvas. Next to it is Fit effects to drawing (active only while the add-on is on): each effect is scaled to the size of the drawing and centered on the drawing rather than on the canvas. Effects have readable names (for example "Lens Flare H"). The parameters are reset with the arrows next to the values.

Common parameters

  • Element count - the number of elements, Element scale - their size, Element spacing - the distance.
  • Size, Line thickness, Edge softness (0.5 by default), Vignette, Noise.
  • Seed / Random seed.
  • Glass highlight and other specific parameters appear depending on the selected effect.

Material packs (Metals, Wood, Liquids, etc.) create texture blanks, while gameplay packs create animated effects; multi-frame results behave like generated animations.
