Обзор генераторов

Генераторы создают наборы спрайтов: вариации вашего рисунка или полностью новые объекты. Результат - обычные пиксели, которые можно доработать.

Режимы и надстройки

В списке режимов панели Generation toolbar («Choose what to create») доступны Drawing и Tiles. Остальные генераторы - надстройки (add-on) над Drawing: каждый включается флажком в собственном окне настроек, и тогда кнопка Generate запускает именно его вместо обычных вариаций рисунка.

Окна настроек доступны из меню панели генерации: Drawing (Border settings, Noise settings, Auto generator, Tile Repeat settings), Effects, Furniture, UI и Character. При смене режима окно настроек открывается автоматически. Кнопка «Settings...» рядом со списком открывает окно текущего генератора.

Панель Generation toolbar

  • Список режимов и количество: «sprites» (число спрайтов, 1-N; предел зависит от размеров), «variants» (число вариантов анимации) или «states» (для UI).
  • Generate - кнопка с волшебной палочкой. Для Effects, Furniture и UI рядом показан также выбор пресета.
  • Generate all frames per variant - если в документе больше одного кадра, каждый вариант проходит по кадрам документа с его порядком и таймингом.

Результаты

Результат появляется в окне Generated sprites и в Preview. Кликните по спрайту - под ним появятся кнопки действий; имя спрайта видно в подсказке.

  • Add to layer - добавить спрайт на новый слой текущего кадра (по центру; больший спрайт обрезается).
  • Insert as new frame - вставить как новый кадр активного слоя; полный спрайт вписывается в холст.
  • Keep in library (Keep for later) - сохранить в библиотеку вместе с настройками.
  • Create variations - родственные варианты. Стрелка рядом открывает Variation options: Preserve shape, Preserve palette, текущий Seed #N и кнопку Repeat with same seed.
  • Save generated sprite / Save sprite as PNG, Save animation as GIF.
  • Для анимаций: добавить текущий кадр на новый слой, вставить все кадры анимации на активный слой, показать вариант (Variant N · frame K/M).

Сид и вариации

  • Random seed / Seed - воспроизводимость: тот же сид и те же настройки дают тот же результат.
  • Add variation / Remove selected variation - несколько независимых вариаций настроек (например, разные профили шума).

Пресеты (Generation presets)

Окно Generation presets (меню Edit) сохраняет текущие настройки генерации под именем и применяет их позже: Preset name, Save preset, Generation preset. Недопустимое имя блокируется («Invalid preset name»).

Предпросмотр

Окно Preview показывает результат генерации или холст («Drawing canvas»). Кнопка New example появляется при наведении курсора в правом нижнем углу окна и показывает другой пример. Для генераторов с полными наборами размер задаётся автоматически («This generator creates a complete set; its size is automatic»).

Генераторы используют координаты «сверху вниз» (строка 0 - верх). Это важно для модов и импорта: см. Моды и Импорт.
