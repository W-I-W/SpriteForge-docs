Generators overview

Generators create sets of sprites: variations of your drawing or entirely new objects. The result is ordinary pixels that you can refine.

Modes and add-ons

The program no longer has a mode selector. Generation always starts from Drawing, and the other generators are add-ons over Drawing: each is turned on by a checkbox in its own settings window, and then the Generate button runs it instead of the plain variations of your drawing.

The settings windows are listed in View > Drawing: Border settings, Noise settings, Auto generator, Effect settings, Furniture settings, UI generation settings, Character settings and Tile Repeat settings. A document remembers which add-on is on. The 48-tile set (Tiles) is not offered in the interface any more; it only runs for documents or presets that were saved in that mode.

The generation controls

The generation controls are in the tab bar of the Sprites window, next to its tab:

  • The count field - the number of results: sprites (1-N; the limit depends on the dimensions), variants for animations, or states for UI. For packs (Effects, Furniture, Character) the count is fixed by the pack.
  • Generate - the magic wand button. Its tooltip: "Generate a sprite set and view the results below."
  • Generate all frames per variant - a toggle that appears when the document has more than one frame: each variant runs through the document's frames with their order and timing.

Results

The result appears in the Generated sprites window and in Preview. Click a sprite - action buttons appear under it; the sprite's name is visible in a tooltip.

  • Add to layer - add the sprite to a new layer of the current frame (centered; a larger sprite is cropped).
  • Insert as new frame - insert as a new frame of the active layer; the whole sprite is fitted to the canvas.
  • Keep in library (Keep for later) - save to the library together with its settings.
  • Create variations - related variations. The arrow next to it opens Variation options: Preserve shape, Preserve palette, the current Seed #N and the Repeat with same seed button.
  • Save generated sprite / Save sprite as PNG, Save animation as GIF.
  • For animations: add the current frame to a new layer, insert all frames of the animation onto the active layer, show a variant (Variant N · frame K/M).

Seed and variations

  • Random seed / Seed - reproducibility: the same seed and the same settings give the same result.
  • Add variation / Remove selected variation - several independent variations of settings (for example different noise profiles).

Presets (Generation presets)

The Generation presets window (Edit menu) saves the current generation settings under a name and applies them later: Preset name, Save preset, Generation preset. An invalid name is rejected ("Invalid preset name").

Preview

The Preview window shows the generation result or the canvas ("Drawing canvas"). The New example button appears when the cursor hovers the bottom right corner of the window and shows another example. For generators with complete sets the size is set automatically ("This generator creates a complete set; its size is automatic").

Generators use "top-down" coordinates (row 0 is the top). This matters for mods and import: see Mods and Import.
