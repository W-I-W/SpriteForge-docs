Settings and user content

The Properties window (Edit > Properties..., Program settings) has the tabs General, Appearance, Onion skin, Content and Language.

Tabs

TabContents
GeneralGeneral parameters, including Predict next edit and transferring edits between frames (details). The values are saved between launches.
AppearanceInterface scale (1x-3x, the Auto and 100% buttons; keys Ctrl++ / -, Ctrl+Shift+0), the theme (Dark theme / Light theme), the editable icon atlas (Open icon folder, Reload icons), Atlas PNG, Icon tint, Icon scale (0.5-1.5), Button rounding, Window rounding (0-16), Save style.
Onion skinEnabling it, the number of previous and next frames (0-4) and the opacity (0.05-0.75).
ContentOpen settings folder, Reload from folder and a description of the folders.
LanguageInterface language, Open language folder, Reload languages.

The settings folder

The shared folder: Application.persistentDataPath/Settings. On Windows: %USERPROFILE%\AppData\LocalLow\BowPixel\Sprite Forge\Settings. It is created at launch and survives updates.

FolderPurpose
PalettesPNG, HEX, GPL, JSON palettes. See Palettes.

Languages

English (en) and Russian (ru) are built in. To add a language, put a JSON file into Settings/Languages and press Reload languages. The file structure:

{
  "code": "en",
  "name": "English",
  "font": "LiberationSans.ttf",
  "strings": {
    "Outline filter": "Outline",
    "Save": "Save"
  }
}
  • The key is the English interface string, the value is the translation. Missing strings fall back to English.
  • font - the name of the font file in Settings/Fonts (TTF or OTF), without paths. For CJK languages put a suitable font there.
  • If the font fails to load, the program reports it and uses a fallback.

Icons

You can put your own atlas SpriteForgeIcons.png and a style.json into SpriteForgeIcons. The atlas dimensions and the icon positions (64 pixel cells) must match the original. The file is at most 16 MiB. Reload icons applies them without a restart. If there is no PNG, the built-in icons are used.

{
  "atlas": "SpriteForgeIcons.png",
  "tint": "#FFFFFFFF",
  "scale": 1.0,
  "frameRounding": 6.0,
  "windowRounding": 8.0
}

The result library and styles

  • Application.persistentDataPath/ResultLibrary - the result library.
  • Pencil styles are saved as JSON/PNG through Save pencil style.
