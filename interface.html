Interface

The workspace consists of dockable panels (ImGui docking). Panels can be dragged, grouped into tabs and hidden.

The Documentation, Getting started guide and Keyboard shortcuts items open pages of this documentation in a browser: the files are taken from the docs folder next to the program (in the editor - from the project folder). If the folder is missing, the status bar shows "Documentation not found".

Interface scale

The interface can be enlarged from 1x to 3x: Properties > Appearance > Interface scale. The Auto button picks a scale for the screen, 100% restores the original. The Ctrl++ and Ctrl+- keys change the scale, Ctrl+Shift+0 turns on automatic selection.

Controls

  • Sliders and fields - Ctrl+click on a slider lets you type an exact value. If a value differs from its default, a reset arrow (Reset to default) appears on the right and disappears when the value is the default. Long labels are cut with an ellipsis; the full text is in the tooltip.
  • Image zoom in a window - in windows with pictures a zoom slider appears in the bottom right corner when the cursor is over the window.
  • Tooltips - hover over a button or icon.

Status bar

The bottom shows the document name, the active tool, the layer, the frame (Frame 3/12) and the canvas zoom. Error messages and operation results (saved, filter applied, etc.) are also shown here. Without a document it shows "No document".

Panel layout

  • Drag a panel title to dock it to an edge or to another panel.
  • View > Reset panel layout restores the default layout.
  • A closed panel can be brought back from the View menu.

Several documents

The program works with several documents at once (menu File > Documents; unsaved ones are marked with an asterisk). A shared estimated memory budget of 1 GiB applies to all open documents: creating, importing, resizing and duplicating layers/frames check the resulting size in advance and refuse without partial changes if the budget would be exceeded. Each document has its own Undo/Redo history.
