Results and library

The Generated sprites window holds temporary results, the Result library holds permanent ones.

Generated sprites

Shows the results of the last generation. They are temporary: the next generation replaces them. The actions on a result are described in the generators overview. Click a sprite card - action buttons appear under it; clicking again hides them. The sprite's name is shown in a tooltip on hover, and the preview size slider appears in the corner of the window while the cursor is over it (or Ctrl + mouse wheel).

  • Keep in library - save a good variant to the result library.
  • Create variations - create variations of the sprite; the arrow next to it opens the parameters (Preserve shape, Preserve palette) and a button to repeat with the same seed.
  • Save sprite as PNG - save the sprite as a PNG (an animation as a GIF).
  • Add sprite to a new layer - insert the sprite as a new layer.
  • Insert sprite as a new frame - insert the sprite as a new frame of the active layer.

Result library

Open it through View > Result library. The library stores an image together with the generation settings.

  • Name and tags (Tags (comma separated)), the Favorite mark, the Favorites only filter.
  • Search by names and tags ("Search names and tags").
  • Add to layer () / insertion into the document; Apply saved settings applies the saved generation settings (including variations and noise).
  • Export PNG, Refresh library, Delete result from library ().

The storage is in Application.persistentDataPath/ResultLibrary and is independent of the generator's temporary results. Invalid PNGs are rejected ("Invalid library PNG").
