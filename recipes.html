Step-by-step recipes

Ready-made routes for typical tasks. Each one uses only features described in the documentation sections.

1. A symmetric character "blank" with variations

  1. Create a 32 x 32 document (File > New document).
  2. In Tools hold the button of family 5 and choose Mirror; in Mirror settings turn on the Left / right axis and both modes (During drawing and During generation).
  3. Draw half of the figure with the pencil (B) and set a few colors in the palette.
  4. For the main shape keep Body chance at 100%, for details set 30-60% (Palettes).
  5. Press Generate in the Sprites window tab bar. Open a result you like and press Create variations to get related ones.
  6. Keep in library - save a good one; Add to layer - place it on the canvas.

2. A walk animation for Unity

  1. Draw the first frame on a layer. Layers for body parts (Head, Body, Legs) make editing easier.
  2. In the Timeline add frames (Insert) or duplicate the current one (Ctrl+Insert) and edit the poses. For smoothness use Onion skin and Inbetween (Ctrl+I).
  3. Select the frames of a layer (Shift+click) and press Ctrl+Shift+T (Create animation): name the animation walk. Repeat for idle.
  4. Set the FPS and, if needed, the duration of individual frames (Frame duration).
  5. File > Export... → Engine atlas → Unity (JSON), set Pixels per unit. The animations become clips.
  6. Save the .sf project.

3. A seamless tile

  1. Create a square document (for example 16 x 16 or 32 x 32).
  2. Turn on Tile Repeat (View > Drawing > Tile Repeat settings): Horizontal tiles and Vertical tiles = 3. Draw the texture - the seams will match.
  3. Add frames for variants if you need a set, and export them through the Tileset mode (Columns, Spacing).

4. From an AI picture to a game sprite

  1. Filter > AI image to pixel art..., load a PNG/JPG.
  2. Press Detect grid; if the grid was detected with low confidence, adjust Source pixel cell size and the offset.
  3. Choose a Conversion style and set Maximum colors (for example 16).
  4. Turn on Ink outlines or Line thickness 1; for noisy images use Noise reduction and Pixel art cleanup.
  5. Create document or Add to canvas as new frame; refine by hand.

5. A UI set for a game

  1. Create a document of 64 x 64 or larger (for details).
  2. Open UI generation settings (View > Drawing), turn on Apply UI to Drawing, choose a Component (for example Button) and a Style.
  3. Set Border/Corner/Padding pixels and colors (Use palette colors).
  4. Turn on Generate separate UI parts and press Generate: each part is a separate sprite.
  5. For scalable elements define a Slice with a 9-slice center and export the slice.

6. A falling object with a bounce

  1. Draw the object on the current frame.
  2. Open Physics animation, set a name and the frame count (at least 3).
  3. Set Elasticity, Squishiness and Material strength; the gravity direction and magnitude; a push if needed.
  4. Check Preview frame and create the animation - the frames are added to the Timeline as a new animation.
