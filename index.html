SpriteForge

A pixel art editor with layers, animation and a set of generators: characters, furniture, effects, tiles, UI components and noise. This documentation describes every tool and window of the program.

The main workflow

The program is built around a chain: create - configure - generate - edit - export.

  1. Create a canvas (File > New document) or open a recent project.
  2. Turn on the generator you need (for example an add-on checkbox in its settings window) and configure it.
  3. Press Generate and save the good results to the library.
  4. Add a result to a layer or frame and refine the pixels with the tools.
  5. Export a PNG, sprite sheet or GIF; save .sf to continue later.

Program windows

Frame numbers in the interface start at 1. The canvas origin is the top left corner: X grows to the right, Y grows downward.
