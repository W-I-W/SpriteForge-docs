Tools

The program has 28 tools: drawing, shapes, selection, navigation and three special tools (lighting, mirror, noise fade area).

The Tools panel

Next to the tool buttons, Tool settings always show the default values: if a parameter has been changed, a reset arrow appears beside it.

The Tools panel shows ten buttons. A button with an arrow in the corner hides a family of related tools: hold it for about 0.1 seconds (or click and hold) and a menu of variants appears. Release the mouse button over the variant you want - it becomes the one selected for that button. A simple click selects the tool currently shown on the button.

General rules for all drawing tools: they work on the active layer and frame; locked and hidden layers are not changed; if there is an active selection, drawing is limited to it; strokes are recorded in the Undo history. With Mirror and Tile Repeat on, the action is mirrored/repeated automatically (details).

Drawing

Pencil B

The main drawing tool. It draws with the current palette color (Color Pencil) using a brush of the given size and shape. Hold Ctrl to switch temporarily to the color picker.

  • Brush size - the brush size in pixels (1-50, 1 by default); also changed with Ctrl+wheel on the canvas.
  • Brush shape - Square, Circle, Diamond or Custom. For the circle and the square a Brush corner radius (px) is available.
  • Custom - your own stamp up to 32 x 32: click cells in the Edit pencil stamp window, change Stamp width / Stamp height, load a stamp from JSON or a transparent PNG, and save a style (Save pencil style / Load pencil style). The Copy selection to pencil button turns the current selection (up to 32 x 32, with painted pixels of the active layer) into a stamp.
  • Pixel-perfect - removes extra corner pixels with a 1 px brush so the line is "clean".
  • Advanced paint settings - generation parameters for the drawn pixels: Body and Outline (enabled or not), Chance (probability of use), AutoColor and the generation colors. They are stored in the cells together with the pixels and define how generators will interpret the drawing. See Palettes.

Spray Shift+B

Spraying: at each step the brush paints a random part of its pixels. The Density % parameter (1-100, 25 by default) sets the share of pixels painted. The spray also has the Body/Outline and Chance drawing parameters. The brush size and shape are the same as for the pencil.

Eraser E

Erases pixels on the active layer (makes them transparent). The brush size and shape are set the same way as for the pencil.

Color picker I or hold Ctrl

A click on a pixel on the canvas takes its color and its drawing properties (Body/Outline, Chance, etc.). Your other tool choice is not lost: while Ctrl is held over the canvas, any drawing tool temporarily works as a picker (outside the canvas Ctrl does nothing).

Fill G

Fills an area with a color. Two modes:

  • Contiguous (default) - only the connected area under the cursor is filled.
  • Fill by color - all matching pixels of the active layer are replaced (within the selection, if there is one).
  • Tolerance (0-255, 0 by default) - the color difference allowed when deciding what counts as "the same" color.

The Fill settings also have the Fill/Outline generation parameters for the filled pixels (as for the pencil).

Gradient Shift+G

Drag from the point with the main color to the point with the End color. The gradient fills the layer or the active selection. The Ordered dithering checkbox replaces the smooth transition with ordered dithering - so the gradient stays "pixelated" and uses a limited number of colors.

Blur

A brush that softens the transitions between the colors under it. The Strength parameter (0.01-1, 0.5 by default) is the strength of the effect. The brush size is set as for the pencil.

Jumble

A brush that shuffles the pixels under it: useful for ragged edges, noise and texture. Strength sets the intensity.

Lines and shapes

Line L

Drag the cursor between two pixels to get a straight line as thick as the brush size.

Curve Shift+L

Drag a line, then drag the endpoints or click/drag somewhere to bend the curve. Enter accepts a straight curve, Esc cancels.

Rectangle / Filled rectangle U

Drag the cursor diagonally. Rectangle draws an outline, Filled rectangle draws a filled rectangle. The outline thickness equals the brush size.

Ellipse / Filled ellipse Shift+U

Drag the cursor to draw an ellipse (or circle). The Filled version fills the inside.

Contour D

Trace an area freehand. When you release the button the boundary closes and the inside is filled.

Polygon Shift+D

Click to add vertices. A double click or Enter finishes the polygon, Esc cancels. The Finish and Cancel buttons in Tool settings duplicate these actions.

Selection

All selection tools share a common set of modes: Replace, Add, Subtract, Intersect (menu Select > Mode). Keyboard modifiers: Shift - add, Ctrl or Alt - subtract, Shift+Ctrl - intersect. Delete clears the selected pixels, Ctrl+D deselects. More: Selection and transform.

Rectangular marquee M

Drag to select a rectangle. Dragging inside the selection moves its pixels.

Elliptical marquee Shift+M

Drag to select an ellipse.

Lasso Q

Trace an area freehand; the outline closes when you release the button.

Polygonal lasso Shift+Q

Place vertices with clicks; a double click or Enter closes the selection.

Magic wand W

Selects pixels similar in color to the pixel under the cursor. Contiguous limits the choice to a connected area, Tolerance (0-255) sets the allowed color difference. The parameters are also available in the Select > Magic Wand menu.

Moving and navigating

Move V

Moves the selection or, if there is no selection, the whole active cell (the layer in the current frame). Esc cancels the drag, and Undo reverts the move.

Hand H

Drag in the canvas area to pan the view.

Zoom Z

Hold the left mouse button and drag right to zoom in, left to zoom out. The point where the drag started stays fixed. F fits the canvas to the window.

Slice Shift+C

Creates named rectangular areas ("slices") of the document: drag an area, click a slice to select it. In the settings:

  • Name, X, Y, Width, Height - the bounds in canvas coordinates from the top left corner.
  • Pivot with relative coordinates Pivot X / Pivot Y.
  • 9-slice center - the center area for scalable UI elements (Center X, Center Y, Center width, Center height).
  • Export PNG - save the contents of the slice; Delete slice - delete it.

The C key (without Shift) is responsible for resizing the canvas: after pressing it, drag an edge or corner.

Special tools

Frame lighting

Places a light source for the current frame: a click or drag on the canvas moves the light (for directional light it sets the direction from the center). The lighting parameters are in the Lighting window and in Tool settings. See Frame lighting.

Mirror

Choosing the tool turns on symmetry and the display of the axes; the center can be dragged with the mouse. Parameters: the Canvas symmetry switch, the mode (During drawing / During generation), four independent axes (left-right, top-bottom and two diagonals), Show mirror lines, Center (px), Center in canvas. Esc exits the tool. See Mirror and Tile Repeat.

Noise fade area

Appears when editing the Auto noise fade area: drag the edges and corners to change the shape of the noise silhouette. See Auto noise.
