Quick tour

A short interactive tour of the main workflow: create, draw, turn on the mirror, generate, place and export. It replaces the former learning game.

How to start it

  • Menu Help > Quick tour (the Help menu also contains Documentation on F1, Getting started guide and Keyboard shortcuts).
  • The tour dims the rest of the screen and outlines the element you need to use. The dimming does not block input.
  • Each step finishes by itself when you perform the action. The tour can be skipped at any step with the Skip tour button; at the end "Tour complete" is shown.

Steps

  1. New document. Open File and choose New document - this is your canvas.
  2. Canvas size. Pick a size, for example 32 px, and press Create document.
  3. Draw a base. Draw a simple shape with the pencil, even a square: the generator will color it and offer variations.
  4. Lighting. Light works during generation. Turn it on, drag the light point and adjust the strength and size; the effect is visible in Preview.
  5. Symmetry. Hold the button with the arrow on the toolbar and choose Mirror: the drawing will be mirrored.
  6. Mirror axes. Turn on all four reflection axes: left-right, top-bottom and both diagonals (the counter shows "Axes on: N/4").
  7. Preview. The Preview window shows how the generator will apply the mirror. The New example button shows other variations.
  8. Generate. Press the magic wand button: the variations appear in the Sprites window.
  9. Your variations. Click a sprite you like - action buttons appear under it.
  10. Result to canvas. The plus button under the selected sprite adds it to the canvas as a new layer.
  11. Export. File > Export to save a PNG or GIF.

If a needed window is closed, the tour opens it for you (canvas, Tools, Tool settings, Sprites, Lighting, Preview). Details for each step are in Mirror, Generators, Frame lighting and Export.
