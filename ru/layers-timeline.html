Слои и Timeline

Окно Timeline объединяет слои, кадры, теги анимаций и воспроизведение. Максимум - 120 кадров в документе.

Слои

  • + Layer / Add layer добавляет слой. Перетаскивайте слой за имя, чтобы изменить порядок.
  • Значки Show / hide layer (, глаз) и Lock layer (, замок): скрытые и заблокированные слои не рисуются инструментами и не меняются фильтрами.
  • Клик по имени слоя (двойной клик) открывает его параметры:
    • Opacity и Blend mode: Normal, Multiply, Screen, Add. Влияют на холст и экспорт.
    • Chance - вероятность использования слоя генератором.
    • Layer group - создать/назначить группу, переименовать, Group visible, Group locked, Remove layer group (слои остаются). Группы плоские.
    • Alpha mask layer - маска по альфа-каналу другого слоя в том же кадре, с Invert mask. Скройте слой-источник, если он нужен только как маска. Маски не вычисляются рекурсивно.
  • Группы и маски сохраняются при перестановке слоёв, Undo и сохранении .sf; старые файлы открываются как раньше.
  • Delete layer удаляет слой (Delete удаляет выбранный кадр или слой).

Кадры

  • + Frame / Add frame (Insert) добавляет пустой кадр, Duplicate frame (Ctrl+Insert) дублирует.
  • Delete frame / Backspace - удалить текущий кадр; Delete - выбранные кадры.
  • Выбор кадров: Ctrl+клик - несколько, Shift+клик - диапазон, Ctrl+A - все.
  • Копирование кадров Ctrl+C и вставка после текущего Ctrl+V. Лимит - 120 кадров.
  • Перетаскивайте номер кадра, чтобы переставить: на левый или правый край чужого кадра (вставка до/после), на цветную полосу тега (в начало или конец диапазона). Alt при отпускании вставляет без тега; зона Untagged переносит кадр за пределы всех тегов.
  • Длительность каждого кадра: Frame duration (ms, 0 = FPS). Значение 0 использует общий FPS.

Теги анимаций

Над слоями показываются цветные полосы с именами анимаций (idle, walk, attack, run, jump, hurt, death, roll, cast или своё имя).

  • Создать: выделите диапазон кадров слоя и нажмите ПКМ → Add tag, либо Ctrl+Shift+T, либо введите имя и диапазон в окне Animation and onion settings (Create animation).
  • Клик по полосе выбирает диапазон и его первый кадр; Play проигрывает выбранную анимацию. Пересекающиеся диапазоны размещаются в отдельных строках.
  • Клик по цветному тегу открывает его параметры: имя, диапазон, цикл (Loop), набор слоёв (Layers in this tag), удаление (Delete tag).
  • Слой можно перетащить за имя на тег, чтобы включить в набор; состав сохраняется в проекте.
  • Ячейки кадров получают цвет своего набора. Если извлечён последний кадр, пустой тег удаляется; вставка без тега внутрь диапазона разделяет его на две полосы с тем же именем.

Параметры анимаций и кадров

  • Кнопка Settings в Timeline открывает компактные параметры: Frame duration (ms, 0 = FPS) текущего кадра, Animation name (переименование выбранной анимации), Delete animation, onion skin и график ImPlot.
  • Список слева позволяет показать All frames или кадры конкретной анимации; пункт + Animation создаёт новый тег.
  • Выпадающие списки Play from / Play through и флажок Loop определяют воспроизведение диапазона.
  • Имя анимации не может быть пустым («Enter an animation name»); без выбранной анимации rename недоступен («Select an animation to rename it»).

Воспроизведение

  • Space - играть/остановить (когда Timeline в фокусе); кнопки First frame (Home), Previous (←), Next (→), Last frame (End).
  • Frames per second - общий FPS. Play from / Play through, Play once, Loop range - режимы диапазона.
  • Кнопки «Previous 60 frames» / «Next 60 frames» листают страницы таймлайна (Frames N-M / total).
  • График Frame timing (ImPlot) показывает длительность каждого кадра, если собрано с UIMGUI_ENABLE_IMPLOT.

Onion skin

Показывает до 4 предыдущих и до 4 следующих кадров полупрозрачно (Previous onion frames, Next onion frames, Onion opacity). В окне предпросмотра подсказка: «Frame preview (onion skin): previous and next frames».

Inbetween: промежуточные кадры

Ctrl+I открывает режимы Inbetween для двух выбранных кадров (Ctrl+клик):

  • Midpoint - сдвинуть спрайт в середину без растяжения.
  • Motion stretch - нарисовать слегка вытянутую промежуточную позу.
  • Full motion trail - нарисовать путь от первого кадра ко второму.
  • Режимы можно выбрать для диагонального, горизонтального и вертикального направления.

Новый кадр добавляется после первого из двух; программа пишет: «Intermediate frame (режим) added after frame N».

Импорт листа спрайтов

File > Import sprite sheet открывает предпросмотр изображения с параметрами: Cell width / height, Horizontal / Vertical margin, Horizontal / Vertical spacing, Columns (0 = auto), Rows (0 = auto), Frame limit (0 = all), FPS. Ячейки читаются слева направо и сверху вниз в новый несохранённый документ с анимацией. Кнопка Import frames создаёт документ.
