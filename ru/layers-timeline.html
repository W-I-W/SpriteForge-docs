Слои и Timeline

Окно Timeline объединяет слои, кадры, анимации и воспроизведение. Максимум - 120 кадров в документе.

Окно Timeline

  • Панель инструментов (пункты 1-7 на схеме): Play / Stop, Loop, список FPS, кнопки перехода по кадрам со счётчиком «кадр / всего», Duplicate frame, Delete, режимы Inbetween и Onion skin.
  • Строка Animation (пункт 8): список Animation и кнопка Settings. В списке - All frames или одна анимация; выбор анимации ограничивает Timeline, воспроизведение и нумерацию кадров её кадрами.
  • Таблица: в верхней строке - кнопка + Layer, заголовки с номерами кадров и кнопка + Frame; ниже слои (сверху самый верхний слой) с ячейками кадров.

Слои

  • + Layer (левый верхний угол таблицы) добавляет слой. Новый слой входит в текущую анимацию. Перетаскивайте строку слоя за имя, чтобы изменить порядок.
  • Значки Show / hide layer (, глаз) и Lock layer (, замок) находятся слева у каждого слоя: скрытые и заблокированные слои не рисуются инструментами и не меняются фильтрами.
  • Двойной клик по имени слоя открывает его параметры:
    • Name, Opacity и Blend mode: Normal, Multiply, Screen, Add. Влияют на холст и экспорт.
    • Generation chance - вероятность использования слоя генератором.
    • Layer group - создать/назначить группу (Create layer group), переименовать, Group visible, Group locked, Remove layer group (слои остаются). Группы плоские.
    • Alpha mask layer - маска по альфа-каналу другого слоя в том же кадре, с Invert mask. Скройте слой-источник, если он нужен только как маска. Маски не вычисляются рекурсивно.
    • Create animation - создаёт анимацию из выбранных кадров (см. ниже).
  • Группы и маски сохраняются при перестановке слоёв, Undo и сохранении .sf; старые файлы открываются как раньше.
  • Delete удаляет выбранный слой или кадры: после клика по имени слоя Delete удаляет слой, после выбора кадров - кадры.

Кадры

  • Числа в строке заголовков - номера кадров внутри текущей анимации; заголовок кадра окрашен цветом его анимации. Точка в углу заголовка отмечает кадр с включённым освещением кадра.
  • Duplicate frame (Ctrl+Insert) дублирует текущий кадр; кнопка + Frame в конце строки добавляет кадр: подсказка - «Duplicate frame» или, для пустой анимации, «Append a blank frame to this animation». Insert добавляет кадр с клавиатуры.
  • Delete selected frames (Backspace или Delete).
  • Выбор кадров: Ctrl+клик - несколько, Shift+клик - диапазон, Ctrl+A - все кадры анимации.
  • ПКМ по заголовку кадра открывает меню: Copy frames (Ctrl+C), Paste frames after current (Ctrl+V) и Create animation (Ctrl+Shift+T). Лимит - 120 кадров.
  • Перетаскивайте заголовок кадра, чтобы изменить порядок внутри анимации: синяя линия показывает место вставки, подсказка - «Release to reorder frames in this animation». Границы анимаций при этом сохраняются.
  • Длительность каждого кадра: Settings → Frame duration (ms, 0 = FPS). Значение 0 использует общий FPS.
  • Удерживайте Shift и вращайте колесо мыши над Timeline, чтобы листать кадры.

Анимации

Анимация - именованный диапазон кадров со своей настройкой цикла и набором слоёв. В документе может быть несколько анимаций (idle, walk, attack, jump, hurt, death, cast или свои имена); Timeline показывает одну анимацию или All frames. При экспорте анимации становятся клипами (см. Экспорт).

  • Выбор анимации - в списке Animation. Имена со слешем (например, walk/left) группируются в подменю.
  • Создать новую - пункт + Animation в конце списка: введите имя и нажмите Create animation; новая анимация начинается с пустого кадра.
  • Создать из существующих кадров: выделите кадры и выберите Create animation (контекстное меню кадра, параметры слоя или Ctrl+Shift+T). Если выбранные кадры идут подряд, они становятся анимацией; если нет, их копии добавляются в конец таймлайна, чтобы пропуски не вошли в анимацию. Введите имя и нажмите Create animation.
  • Settings открывает параметры текущей анимации: Frame duration (ms, 0 = FPS) текущего кадра, Animation name (переименование; при All frames появляется «Select an animation to rename it») и Delete animation.
  • Loop хранится для каждой анимации отдельно.
  • Заголовки и ячейки кадров окрашиваются цветом своей анимации. В режиме All frames при пересечении диапазонов цвет задаёт самая новая анимация.

Воспроизведение

  • Space - играть/остановить (когда Timeline в фокусе); кнопки First frame (Home), Previous (←), Next (→), Last frame (End).
  • FPS - общая скорость: в списке 6, 8, 12, 15, 24, 30 и 60, а поле позволяет ввести значение от 1 до 60. Индивидуальные длительности кадров имеют приоритет.
  • Воспроизведение идёт по выбранной анимации (или по всем кадрам) и учитывает Loop.

Onion skin

Кнопка Onion skin на панели показывает до 4 предыдущих и до 4 следующих кадров полупрозрачно. Число кадров и непрозрачность задаются на вкладке Onion skin окна Edit > Properties (Previous onion frames, Next onion frames, Onion opacity).

Inbetween: промежуточные кадры

Кнопка Inbetween modes (Ctrl+I) предлагает три способа вставить кадр между двумя выбранными (выберите их Ctrl+кликом, иначе появится «Select two frames with Ctrl+click first»):

  • Midpoint - сдвинуть спрайт в середину без растяжения.
  • Motion stretch - нарисовать слегка вытянутую промежуточную позу.
  • Full motion trail - нарисовать путь от первого кадра ко второму.

Новый кадр добавляется после первого из двух; программа пишет: «Intermediate frame (режим) added after frame N».

Импорт листа спрайтов

File > Import sprite sheet открывает предпросмотр изображения с параметрами: Cell width / height, Horizontal / Vertical margin, Horizontal / Vertical spacing, Columns (0 = auto), Rows (0 = auto), Frame limit (0 = all), FPS. Ячейки читаются слева направо и сверху вниз в новый несохранённый документ с анимацией. Кнопка Import frames создаёт документ.
