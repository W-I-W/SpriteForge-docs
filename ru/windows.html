Справочник окон

Все окна программы: как открыть и для чего нужны. Идентификаторы нужны модам (SpriteForgeModApi.SetWindowVisible).

Рабочие панели

ОкноId для модовЧто делает
CanvascanvasХолст с линейками, сеткой, направляющими. Колесо - масштаб (1x-64x), Ctrl+колесо - размер кисти (1-50). Подробнее.
ToolstoolsДесять кнопок-семейств инструментов. Инструменты.
Tool settingstool-settings, palettesПараметры активного инструмента. Здесь находится палитра: вверху - образцы палитры рисования (см. Палитры), ниже - параметры Fill / Outline и цвета генерации. Для инструментов Mirror, Frame lighting и Noise fade area показывает их собственные настройки.
PreviewpreviewПредпросмотр документа или результата генерации (источник выбирается списком), кнопка New example.
TimelinetimelineСлои, кадры, теги анимаций, воспроизведение. Слои и Timeline.
Generation toolbargeneration-toolbarНе отдельное окно: его элементы находятся в строке вкладок окна Sprites - число спрайтов/вариантов/состояний, кнопка Generate (волшебная палочка) и переключатель «Generate all frames per variant».
Sprites (Generated sprites)generated-spritesРезультаты последней генерации и действия над ними. В строке вкладок - элементы генерации.
Result libraryresult-libraryПостоянная библиотека результатов. Библиотека.
LightinglightingОсвещение при генерации и освещение кадра. Освещение.
GuidesguidesЛинейки и направляющие.
History performancehistory-performanceРазмер истории и замеры. История.

Диалоги и вспомогательные окна

ОкноКак открытьЧто делает
New documentFile > New document (id new-document)Имя, ширина и высота (по умолчанию 32 x 32), кнопки типовых размеров. Показывает оценку памяти «Estimated memory: X / Y MiB». Ошибки: пустое имя, превышение размера текстуры, превышение бюджета памяти.
Import sprite sheetFile > Import sprite sheetНарезка листа на кадры: размер ячейки, поля, интервалы, колонки/строки, лимит кадров, FPS. Импорт.
Drop dialogПеретаскивание файла в окноДля PNG, JPG или .aseprite: Create new document или Insert into current document (доступно, если есть редактируемый документ), либо Cancel. Показывает размер изображения.
Resize canvasEdit > Resize canvas... (id expand-canvas)Новая ширина и высота, девять якорей. Холст.
Replace colorEdit > Replace color in document (id replace-color)Замена цвета во всех слоях и кадрах.
Color limit / Color indexing / Inversion / Saturation / Gamma / OutlineМеню Filter (id color-limit, color-index, invert-colors)Фильтры. Фильтры.
Palette toolsFilter > Palette toolsRamps, Hue shift, Replace colors, Indexed, Palette swap.
AI image to pixel artFilter > AI image to pixel art... (id ai-pixel-art)Преобразование изображения.
Export spritesFile > Export... (id export)Экспорт.
PropertiesEdit > Properties... (id user-settings)Настройки.
Unsaved changesЗакрытие документа или выход«Save changes to ...?»: Save and close, Discard changes, Cancel.
Recover unfinished workЗапуск после сбоя; File > Recover allВосстановление документов из автосохранения, счётчики Recovered / Failed, кнопка Stop after this document. Восстановление.
Mod windowsРегистрируются модамиМоды.
