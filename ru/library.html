Результаты и библиотека

Окно Generated sprites хранит временные результаты, Result library - постоянные.

Generated sprites

Показывает результаты последней генерации. Они временные: следующая генерация их заменяет. Действия над результатом описаны в обзоре генераторов. Кликните по карточке спрайта - под ней появятся кнопки действий; повторный клик скрывает их. Имя спрайта показывается подсказкой при наведении, а ползунок размера превью появляется в углу окна, пока курсор над ним (или Ctrl + колесо мыши).

  • Keep in library - сохранить удачный вариант в библиотеку результатов.
  • Create variations - создать вариации спрайта; стрелка рядом открывает параметры (Preserve shape, Preserve palette) и кнопку повтора с тем же начальным значением.
  • Save sprite as PNG - сохранить спрайт как PNG (анимацию как GIF).
  • Add sprite to a new layer - вставить спрайт новым слоем.
  • Insert sprite as a new frame - вставить спрайт новым кадром активного слоя.

Result library

Откройте через View > Result library. Библиотека хранит изображение вместе с настройками генерации.

  • Название и теги (Tags (comma separated)), отметка Favorite, фильтр Favorites only.
  • Поиск по названиям и тегам («Search names and tags»).
  • Add to layer () / вставка в документ; Apply saved settings применяет сохранённые настройки генерации (включая вариации и шум).
  • Export PNG, Refresh library, Delete result from library ().

Хранилище находится в Application.persistentDataPath/ResultLibrary и не зависит от временных результатов генератора. Некорректные PNG отклоняются («Invalid library PNG»).
