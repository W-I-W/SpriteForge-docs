Быстрый старт

От пустого холста до готового PNG или GIF. Если удобнее учиться на месте - запустите Quick tour из меню Help.

1. Создайте документ

Откройте File > New document. Введите имя, выберите ширину и высоту (по умолчанию 32 x 32) или нажмите кнопку типового размера и нажмите Create document. Под полями показана оценка памяти; при слишком большом размере программа сообщит об ошибке.

На пустом холсте доступны последние 12 открытых или сохранённых проектов.

2. Нарисуйте основу

  • B - карандаш, E - ластик, G - заливка, I - пипетка.
  • Цвета выбираются в окне Palettes. Для каждого цвета можно задать параметры тела (Body) и контура (Outline) и вероятность их применения генератором.
  • Включите Mirror, если рисуете симметричный объект.
  • Колесо мыши - масштаб, Ctrl+колесо - размер кисти.

Подробно: Инструменты.

3. Сгенерируйте

В панели Generation toolbar режим по умолчанию - Drawing: генератор создаёт варианты вашего рисунка. Для остальных генераторов откройте их окно настроек и включите флажок Apply ... to Drawing (Effects, Furniture, UI, Character) либо выберите Tiles. Нажмите кнопку с волшебной палочкой (Generate): результаты появятся в окне Generated sprites.

  • Keep in library - сохранить результат вместе с настройками.
  • Add to layer - добавить спрайт на новый слой текущего кадра.
  • Вставить спрайт как новый кадр активного слоя или вставить все кадры анимации.
  • Create variations - создать родственные варианты выбранного спрайта.

4. Доработайте

Результат - обычные пиксели на слое. Исправьте их инструментами, добавьте контур (Filter > Outline filter), измените палитру (Фильтры), создайте кадры в Timeline.

5. Сохраните и экспортируйте

  • Ctrl+S - сохранить проект в формате .sf (слои, кадры, теги и палитры сохраняются полностью).
  • File > Export... - PNG, лист спрайтов, GIF, CSS, .aseprite или атлас для движка. См. Экспорт.

Сохранение PNG или JPEG не считается сохранением проекта: изменения остаются несохранёнными, а копия для восстановления сохраняется до сохранения .sf.

Первые минуты: подсказки

  • Наведите курсор на элемент - почти у каждого есть подсказка.
  • Ctrl+клик по ползунку позволяет ввести точное значение. Если значение отличается от умолчания, рядом появляется стрелка сброса.
  • Клавиша F вписывает холст в окно. Ctrl+Z / Ctrl+Y - отмена и возврат.
  • F1 открывает эту документацию.
  • Слишком мелкий интерфейс: Ctrl++ / Ctrl+- меняют масштаб, Ctrl+Shift+0 подбирает его автоматически.
