Проекты и импорт

Формат проекта .sf, открытие файлов и ввод изображений извне.

Проект .sf

  • Save / Save As (Ctrl+S / Ctrl+Shift+S) и Open (File > Open).
  • Файл хранит пиксели полностью, слои, группы и маски, кадры, длительности, анимации, диапазон воспроизведения, прозрачность и режим наложения слоёв, а также компактный список заполненных ячеек инструментов (Body/Outline и др.).
  • Новые файлы используют AnimationVersion = 3. Старые файлы открываются (непрозрачность слоя 100%, прежний FPS кадров), но новые файлы не предназначены для открытия старой версией программы.
  • Запись выполняется атомарно: при сбое прежний файл остаётся нетронутым.
  • Окно Unsaved changes предлагает Save and close, Discard changes или Cancel при закрытии документа с несохранёнными изменениями.
  • На пустом холсте показываются последние 12 открытых или сохранённых проектов.

Импорт изображений

  • Перетаскивание PNG, JPG или .aseprite в окно открывает диалог: Create new document или Insert into current document (вставка на новый слой текущего кадра; при необходимости изображение масштабируется или обрезается по холсту, программа сообщает об этом).
  • Буфер обмена: вставка изображения (Windows). Если системный буфер недоступен, используется внутренняя копия.
  • Лист спрайтов: File > Import sprite sheet, см. Слои и Timeline.
  • AI image to pixel art: преобразование изображения с восстановлением сетки - страница.
  • Aseprite: открытие файлов .aseprite с сохранением слоёв, кадров, анимаций и длительностей.

Размер файла изображения ограничен. Слишком большие или пустые файлы отклоняются сообщениями «Image file is empty or too large» или «Unsupported image or image dimensions».

Палитры

Импорт палитр из PNG, HEX, GPL и JSON описан на странице Палитры.

Система координат при импорте

Внутри программы строка 0 - верхняя. Импортируемые изображения проходят единственное преобразование строк на границе (чтобы голова осталась сверху), а экспорт делает обратное. Если вы создаёте моды или внешние инструменты, придерживайтесь этого же правила.
