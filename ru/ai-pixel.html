AI image to pixel art

Превращает «псевдо-пиксельное» изображение (например, созданное нейросетью) в настоящий пиксель-арт: находит исходную сетку, выравнивает блоки и сокращает палитру. Работает локально, без сетевых запросов.

Откройте через Filter > AI image to pixel art.... Загрузите PNG или JPG кнопкой Load image....

Шаг 1. Pixel grid

  • Detect grid - автоматически определяет размер «пикселя» в исходнике и смещение. Если определение неуверенное, окно предупреждает - проверьте выравнивание кнопкой Adjust grid.
  • Source pixel cell size (по умолчанию 4) - размер ячейки исходного изображения. 1 обрабатывает отдельные пиксели; бóльшие значения выравнивают блоки.
  • Grid offset X / Y - сдвиг сетки.

Шаг 2. Appearance

Conversion style выбирает способ получить цвет блока:

СтильИдея
Balanced blocksусредняет каждый блок для чистого ровного результата
Sharp edgesберёт пиксель около центра блока, сохраняя чёткие края
High contrastусиливает светлые и тёмные области перед ограничением палитры
Dithered paletteраспределяет ошибку цвета между пикселями (дизеринг) для плавных переходов малым числом цветов
Dominant clustersиспользует самую частую группу цветов в блоке: плотные формы и резкие границы
Posterized shadingгруппирует яркость в четыре полосы - графичные ступенчатые тени
Grayscaleоттенки серого перед ограничением палитры
Handheld greenчетыре ретро-зелёных тона по яркости
Soft pastelосветляет и смягчает насыщенность
Ink outlinesдобавляет тёмный контур в один пиксель вдоль сильных цветовых и силуэтных границ
  • Maximum colors (2-256, по умолчанию 16) - размер итоговой палитры.
  • Separate palette per tile - палитра ограничивается независимо для каждого тайла (Tile width, Tile height в пикселях восстановленной сетки, Show tile grid); во всём изображении цветов может быть больше.
  • Line thickness (0-4 px) - 0 сохраняет исходную ширину контура, 1-4 задают единую ширину в пикселях сетки.
  • Cleanup and extra settings: Noise reduction (0-100, убирает одиночный цветовой шум до сокращения палитры), Pixel art cleanup (0 - выкл.; выше - сливает близкие цвета и чистит мелкие дефекты силуэта), Transparency threshold.

Шаг 3. Result

  • Размер результата показан как «Result: W x H | N colors» («Source: W x H» - размер исходника).
  • Align without resizing - только выровнять и ограничить палитру, не уменьшая изображение.
  • Save PNG... - сохранить результат.
  • Add to canvas as new frame - вставить в документ как новый кадр.
  • Create document - создать новый документ из результата.

Правила ориентации: результат вставляется в документ строкой 0 сверху. Чтобы убедиться в этом, проверяйте преобразование на несимметричном изображении (голова сверху, ноги снизу).
