Интерфейс

Рабочая область состоит из стыкуемых панелей (ImGui docking). Панели можно перетаскивать, группировать во вкладки и скрывать.

Главное меню

МенюСодержимое
FileNew document, Open, Import sprite sheet, Documents (список открытых, когда их больше одного), Save (Ctrl+S), Save As (Ctrl+Shift+S), Export..., Close document (Ctrl+W), Recover all, Exit.
EditUndo / Redo, Copy / Paste selection (Ctrl+C / Ctrl+V), Rotate selection 90 degrees, Flip selection horizontally / vertically, Deselect, Replace color in document, Resize canvas..., Generation presets, Properties.... Копирование кадров и создание тега анимации (Ctrl+Shift+T) находятся в Timeline.
SelectSelect all (Ctrl+A), Select opaque pixels, Invert selection, Deselect (Ctrl+D), Expand / Shrink на заданное число пикселей, режимы выделения (Replace / Add / Subtract / Intersect), параметры Magic Wand.
ToolВыбор любого из инструментов по названию.
FilterOutline filter, Color limit, Color indexing, Inversion, Saturation, Gamma, AI image to pixel art, Palette tools.
ViewПоказать/скрыть окна: Canvas, Preview, Tools, Tool settings, Timeline, Physics animation, Lighting, Sprites, Result library, Guides, Grid size, подменю Drawing с окнами настроек генераторов (Border, Noise, Auto generator, Effect, Furniture, UI generation, Character, Tile Repeat), History performance; также Fit canvas to view (F), Pixel grid (Ctrl+G), Reset panel layout.
HelpDocumentation (F1), Quick tour, Getting started guide, Keyboard shortcuts.

Пункты Documentation, Getting started guide и Keyboard shortcuts открывают страницы этой документации в браузере: файлы берутся из папки docs рядом с программой (в редакторе - из папки проекта). Если папки нет, в строке состояния появится «Documentation not found».

Масштаб интерфейса

Интерфейс можно увеличивать от 1x до 3x: Properties > Appearance > Interface scale. Кнопка Auto подбирает масштаб по экрану, 100% возвращает исходный. Клавиши Ctrl++ и Ctrl+- меняют масштаб, Ctrl+Shift+0 включает автоматический подбор.

Элементы управления

  • Ползунки и поля - Ctrl+клик по ползунку вводит точное значение. Если значение отличается от умолчания, справа появляется стрелка сброса (Reset to default), которая исчезает, когда значение стандартное. Длинные подписи обрезаются многоточием, полный текст виден в подсказке.
  • Масштаб изображения в окне - в окнах с картинками при наведении курсора в правом нижнем углу появляется ползунок масштаба.
  • Подсказки - наведите курсор на кнопку или значок.

Строка состояния

Внизу показываются имя документа, активный инструмент, слой, кадр (Frame 3/12) и масштаб холста. Также здесь выводятся сообщения об ошибках и результатах операций (сохранено, применён фильтр и т. п.). Без документа показывается «No document».

Компоновка панелей

  • Перетаскивайте заголовок панели, чтобы пристыковать её к краю или к другой панели.
  • View > Reset panel layout возвращает расположение по умолчанию.
  • Закрытую панель можно вернуть из меню View.

Несколько документов

Программа работает с несколькими документами одновременно (меню File > Documents; несохранённые помечены звёздочкой). Для всех открытых документов действует общий оценочный бюджет памяти 1 ГиБ: создание, импорт, изменение размера и дублирование слоёв/кадров проверяют итоговый объём заранее и отказывают без частичных изменений, если бюджет превышен. История Undo/Redo у каждого документа своя.
