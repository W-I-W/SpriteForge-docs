Настройки и пользовательский контент

Окно Properties (Edit > Properties..., Program settings) содержит вкладки General, Appearance, Onion skin, Content и Language.

Вкладки

ВкладкаСодержимое
GeneralОбщие параметры, включая Predict next edit и перенос правок между кадрами (подробнее). Значения сохраняются между запусками.
AppearanceInterface scale (1x-3x, кнопки Auto и 100%; клавиши Ctrl++ / -, Ctrl+Shift+0), тема (Dark theme / Light theme), редактируемый атлас иконок (Open icon folder, Reload icons), Atlas PNG, Icon tint, Icon scale (0,5-1,5), Button rounding, Window rounding (0-16), Save style.
Onion skinВключение, число предыдущих и следующих кадров (0-4) и непрозрачность (0,05-0,75).
ContentOpen settings folder, Reload from folder и описание папок.
LanguageInterface language, Open language folder, Reload languages.

Папка настроек

Общая папка: Application.persistentDataPath/Settings. В Windows: %USERPROFILE%\AppData\LocalLow\BowPixel\Sprite Forge\Settings. Создаётся при запуске и переживает обновления.

ПапкаНазначение
PalettesПалитры PNG, HEX, GPL, JSON. См. Палитры.
ModsМоды - библиотеки DLL. См. Моды.
LanguagesФайлы языков (JSON).
FontsШрифты TTF/OTF для языков.
SpriteForgeIcons (Icons)Заменяющий атлас иконок и style.json.

Языки

Встроены английский (en) и русский (ru). Чтобы добавить язык, положите JSON-файл в Settings/Languages и нажмите Reload languages. Структура файла:

{
  "code": "en",
  "name": "English",
  "font": "LiberationSans.ttf",
  "strings": {
    "Outline filter": "Outline",
    "Save": "Save"
  }
}
  • Ключ - английская строка интерфейса, значение - перевод. Пропущенные строки берутся из английского.
  • font - имя файла шрифта в Settings/Fonts (TTF или OTF), без путей. Для CJK-языков положите туда подходящий шрифт.
  • Если шрифт не загрузился, программа сообщает и использует запасной.

Иконки

В SpriteForgeIcons можно положить свой атлас SpriteForgeIcons.png и style.json. Размеры атласа и расположение иконок (ячейки 64 пикселя) должны совпадать с оригиналом. Файл не больше 16 МиБ. Reload icons применяет их без перезапуска. Если PNG нет, используются встроенные иконки.

{
  "atlas": "SpriteForgeIcons.png",
  "tint": "#FFFFFFFF",
  "scale": 1.0,
  "frameRounding": 6.0,
  "windowRounding": 8.0
}

Библиотека результатов и стили

  • Application.persistentDataPath/ResultLibrary - библиотека результатов.
  • Стили карандаша сохраняются как JSON/PNG через Save pencil style.
