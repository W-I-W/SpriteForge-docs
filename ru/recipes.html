Пошаговые сценарии

Готовые маршруты для типичных задач. Каждый использует только функции, описанные в разделах документации.

1. Симметричный персонаж-«болванка» с вариантами

  1. Создайте документ 32 x 32 (File > New document).
  2. В Tools удержите кнопку семейства 5 и выберите Mirror; в Mirror settings включите ось Left / right и оба режима (During drawing и During generation).
  3. Нарисуйте половину фигуры карандашом (B), в палитре задайте несколько цветов.
  4. Для основной формы оставьте Body chance 100%, для деталей поставьте 30-60% (Палитры).
  5. Нажмите Generate в строке вкладок окна Sprites. Откройте понравившийся результат, нажмите Create variations, чтобы получить родственные.
  6. Keep in library - сохранить удачный; Add to layer - поместить на холст.

2. Анимация ходьбы для Unity

  1. Нарисуйте первый кадр на слое. Слои для частей тела (Head, Body, Legs) облегчат правку.
  2. В Timeline добавьте кадры (Insert) или продублируйте текущий (Ctrl+Insert); правьте позы. Для плавности используйте Onion skin и Inbetween (Ctrl+I).
  3. Выделите кадры слоя (Shift+клик) и нажмите Ctrl+Shift+T: создаётся тег, назовите его walk. Повторите для idle.
  4. Задайте FPS и при необходимости длительность отдельных кадров (Frame duration).
  5. File > Export... → Engine atlas → Unity (JSON), укажите Pixels per unit. Теги станут клипами.
  6. Сохраните проект .sf.

3. Бесшовный тайл

  1. Создайте квадратный документ (например, 16 x 16 или 32 x 32).
  2. Включите Tile Repeat (View > Drawing > Tile Repeat settings): Horizontal tiles и Vertical tiles = 3. Рисуйте фактуру - швы будут совпадать.
  3. Если нужен набор вариантов, добавьте кадры и экспортируйте их режимом Tileset (Columns, Spacing).

4. Из AI-картинки в игровой спрайт

  1. Filter > AI image to pixel art..., загрузите PNG/JPG.
  2. Нажмите Detect grid; если сетка определилась неуверенно, подправьте Source pixel cell size и смещение.
  3. Выберите Conversion style, задайте Maximum colors (например, 16).
  4. Включите Ink outlines или Line thickness 1, при шуме - Noise reduction и Pixel art cleanup.
  5. Create document или Add to canvas as new frame; доработайте вручную.

5. Набор UI для игры

  1. Создайте документ 64 x 64 и больше (для деталей).
  2. Откройте UI generation settings (View > Drawing), включите Apply UI to Drawing, выберите Component (например, Button) и Style.
  3. Задайте Border/Corner/Padding pixels, цвета (Use palette colors).
  4. Включите Generate separate UI parts, нажмите Generate: каждая часть - отдельный спрайт.
  5. Для масштабируемых элементов задайте Slice с 9-slice center и экспортируйте слайс.

6. Падающий предмет с отскоком

  1. Нарисуйте предмет на текущем кадре.
  2. Откройте Physics animation, задайте имя и число кадров (не меньше 3).
  3. Поставьте Elasticity, Squishiness, Material strength; направление и величину гравитации; при необходимости толчок.
  4. Проверьте Preview frame и создайте анимацию - кадры и тег добавятся в Timeline.
