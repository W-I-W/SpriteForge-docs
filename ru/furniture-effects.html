Мебель и эффекты

Два генератора с библиотеками готовых типов: интерьерные предметы и визуальные эффекты/материалы.

Furniture

Режим Furniture открывает окно Furniture settings. Выберите Furniture type и настройте форму. Флажок Apply furniture to Drawing в начале окна включает генератор мебели вместо обычных вариаций рисунка. Кнопка Reset furniture settings возвращает значения по умолчанию.

  • Цвета берутся из палитры, как у остальных генераторов.
  • Игровой вид (например, Top down или Platformer) влияет на проекцию предметов.
  • Внутри программы пакеты мебели возвращают данные «снизу вверх», а общий метод конвертации приводит результат к стандартной ориентации - вручную переворачивать результат не нужно.

Effects

Режим Effects и окно Effect settings. Эффекты организованы в пакеты (Effect pack); внутри пакета выбирается конкретный эффект. Флажок Apply effects to Drawing в начале окна запускает генерацию всего пакета эффектов по рисунку на холсте. Рядом - Fit effects to drawing (активен, только когда надстройка включена): каждый эффект масштабируется до размера рисунка и центрируется на нём, а не на холсте. Имя эффекта, создавшего результат, показано на его карточке в окне Generated sprites (добавляется к имени карточки, например «Lens Flare H»). Параметры сбрасываются стрелками возле значений.

Общие параметры

  • Element count - число элементов, Element scale - их размер, Element spacing - расстояние.
  • Size (0 - 1), Line thickness (0 - 8), Edge softness (0 - 1, по умолчанию 0,5), Vignette, Noise.
  • Seed (0 - 9999).
  • Glass highlight и другие специфичные параметры появляются в зависимости от выбранного эффекта.

Edge softness

Edge softness плавно размывает края эффекта: малые значения дают едва заметную растушёвку в один пиксель, максимум размывает примерно до 5% холста. Пиксели за пределами холста считаются прозрачными, поэтому эффекты затухают у границы. При 0,5 (значение по умолчанию) мягкие эффекты хорошо сливаются с рисунком.

Материалы на рисунке

При включённом Apply effects to Drawing материальные пакеты (Metals, Wood, StoneAndGround, Ceramics, GlassAndCrystals, Liquids, FabricsAndLeather, Organic) не парят вокруг рисунка: материал наносится на заполненные пиксели самого рисунка. Прозрачность и контур рисунка сохраняются; светлый и тёмный узор материала перекрашивается цветом, случайно выбранным из палитры. Остальные пакеты накладывают эффект поверх рисунка и перекрашивают только его нейтральные (серые и белые) пиксели.

Материальные пакеты без надстройки создают текстурные заготовки, а игровые - анимированные эффекты; многокадровые результаты ведут себя как сгенерированные анимации.
