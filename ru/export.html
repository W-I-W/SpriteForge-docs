Экспорт

Окно Export sprites (File > Export...) выгружает документ или сгенерированные анимации в разные форматы.

Кнопки окна

  • Choose location and export - открывает диалог сохранения и выгружает выбранные данные в выбранном формате.
  • Cancel - закрывает окно без экспорта.

Источник

Выпадающий список источника выбирает, что экспортировать: кадры документа или (при наличии) сгенерированные анимации. Для документа доступны два режима отбора:

  • Selected animation - именованная анимация (её слои, длительности и цикл).
  • Frame range - диапазон кадров: First frame и Last frame (нумерация с 1).

Индексы кадров и клипов в JSON пересчитываются относительно выгружаемой последовательности. Одинаковый отбор действует для PNG, тайлсета, GIF и CSS.

Engine atlas

  • Unity (JSON) - атлас с Pixels per unit.
  • Godot (JSON + SpriteFrames .tres) - дополнительно создаётся ресурс SpriteFrames; поле Godot resource folder задаёт путь ресурсов внутри проекта.
  • Phaser (JSON atlas with tags) - JSON-атлас, в котором анимации идут как теги.

.aseprite

Экспорт содержит слои, кадры, анимации и длительности. Группы при этом сплющиваются, а маски слоёв не сохраняются. Импорт .aseprite также поддерживается - см. Проекты и импорт.

Ограничения и ошибки

  • Имя файла не должно содержать недопустимых символов.
  • «Output is too large. Reduce scale» - итоговое изображение слишком велико; уменьшите Pixel scale или измените число колонок.
  • Для тайлсета и GIF все спрайты должны иметь одинаковый размер («All sprites must have the same dimensions»).
  • Записи выполняются транзакционно: при сбое существующий файл не теряется.

Экспорт PNG/JPEG не заменяет сохранение проекта: сохраняйте .sf, чтобы не потерять слои и анимации.

Экспорт отдельных частей

  • Слайс - кнопка Export PNG в настройках инструмента Slice.
  • Результат генерации - Save sprite as PNG / Save animation as GIF в Generated sprites.
  • Библиотека - экспорт PNG из Result library.
  • Стили карандаша - JSON или прозрачный PNG (не больше 32 x 32).
