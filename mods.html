Моды

Мод - это .NET-библиотека, которая добавляет окна и вставляет свой интерфейс в существующие панели SpriteForge через ImGui.NET.

Моды выполняются внутри процесса программы и имеют полный доступ к документу и системе. Устанавливайте только доверенные DLL.

Установка

При запуске программа загружает все верхнеуровневые *.dll из папки:

%USERPROFILE%\AppData\LocalLow\BowPixel\Sprite Forge\Settings\Mods

Папка создаётся автоматически. Скопируйте туда DLL и перезапустите программу. Примеры лежат в репозитории: Assets/InternalAssets/Mods/ExampleEmptyWindow~, AIModelFolders~, SentisImageGenerator~ (у каждого есть mod.json и скрипт Install-Mod.ps1).

Интерфейс IMod

public interface IMod
{
    void OnLoad();
    void OnGui();
    void OnUnload();
}

OnGui вызывается в цикле раскладки UImGui, поэтому внутри можно вызывать ImGui.NET напрямую.

Пример: контент внутри Preview

public void OnLoad() => SpriteForgeModApi.RegisterWindowContent("preview", DrawResultChoices);

private void DrawResultChoices()
{
    ImGui.Separator();
    ImGui.Text("My mod results");
    if (ImGui.Button("Use selected result"))
    {
        // Apply the selected result to the active document here.
    }
}

public void OnUnload() => SpriteForgeModApi.UnregisterWindowContent("preview", DrawResultChoices);

Сборка примера

Пример ссылается на сгенерированный Assembly-CSharp.dll, ImGui.NET и UnityEngine.CoreModule из Unity-проекта. Сборка:

dotnet build InternalAssets\Mods\ExampleEmptyWindow~\Build\ModApi.csproj
dotnet build InternalAssets\Mods\ExampleEmptyWindow~\Build\EmptyWindowMod.csproj

Советы

  • Меняя состояние документа, предпочитайте методы рабочих процессов приложения - так интерфейс и отслеживание сохранений остаются согласованными.
  • Всегда снимайте регистрацию окон и содержимого в OnUnload.
  • Строка 0 пикселей документа - верхняя. Не добавляйте вертикальные развороты без необходимости; конвертируйте строки только на границе с внешними изображениями.
