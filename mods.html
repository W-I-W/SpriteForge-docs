Mods

A mod is a .NET library that adds windows and inserts its own interface into existing SpriteForge panels through ImGui.NET.

Mods run inside the program's process and have full access to the document and the system. Install only trusted DLLs.

Installation

At startup the program loads all top-level *.dll files from the folder:

%USERPROFILE%\AppData\LocalLow\BowPixel\Sprite Forge\Settings\Mods

The folder is created automatically. Copy a DLL there and restart the program. Examples are in the repository: Assets/InternalAssets/Mods/ExampleEmptyWindow~, AIModelFolders~, SentisImageGenerator~ (each has a mod.json and an Install-Mod.ps1 script).

The IMod interface

public interface IMod
{
    void OnLoad();
    void OnGui();
    void OnUnload();
}

OnGui is called in the UImGui layout loop, so you can call ImGui.NET directly inside it.

Example: content inside Preview

public void OnLoad() => SpriteForgeModApi.RegisterWindowContent("preview", DrawResultChoices);

private void DrawResultChoices()
{
    ImGui.Separator();
    ImGui.Text("My mod results");
    if (ImGui.Button("Use selected result"))
    {
        // Apply the selected result to the active document here.
    }
}

public void OnUnload() => SpriteForgeModApi.UnregisterWindowContent("preview", DrawResultChoices);

Building the example

The example references the generated Assembly-CSharp.dll, ImGui.NET and UnityEngine.CoreModule from the Unity project. Build:

dotnet build InternalAssets\Mods\ExampleEmptyWindow~\Build\ModApi.csproj
dotnet build InternalAssets\Mods\ExampleEmptyWindow~\Build\EmptyWindowMod.csproj

Tips

  • When changing document state, prefer the application's workflow methods - this keeps the interface and save tracking consistent.
  • Always unregister windows and content in OnUnload.
  • Row 0 of the document pixels is the top row. Do not add vertical flips unnecessarily; convert rows only at the boundary with external images.
