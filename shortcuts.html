File and edit

Ctrl+SSave
Ctrl+Shift+SSave as
Ctrl+WClose the document
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+C / Ctrl+VCopy / paste the selection (in the Timeline - frames)
Ctrl+ASelect all (in the Timeline - all frames)

DeleteClear the selected pixels

Help and interface scale

F1Open the documentation (Help > Documentation)
Ctrl++ / Ctrl+-Increase / decrease the interface scale (1x-3x)
Ctrl+Shift+0Pick the interface scale automatically

Mouse on the canvas
