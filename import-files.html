Projects and import

The .sf project format, opening files and bringing in images from outside.

The .sf project

  • Save / Save As (Ctrl+S / Ctrl+Shift+S) and Open (File > Open).
  • The file stores the pixels in full, layers, groups and masks, frames, durations, animations, the playback range, layer opacity and blend mode, and a compact list of filled tool cells (Body/Outline, etc.).
  • New files use AnimationVersion = 3. Old files open (layer opacity 100%, the former frame FPS), but new files are not meant to be opened by an old version of the program.
  • Writing is atomic: if something fails the previous file stays untouched.
  • The Unsaved changes window offers Save and close, Discard changes or Cancel when closing a document with unsaved changes.
  • On an empty canvas the last 12 opened or saved projects are shown.

Importing images

  • Dragging a PNG, JPG or .aseprite file into the window opens a dialog: Create new document or Insert into current document (insertion onto a new layer of the current frame; if needed the image is scaled or cropped to the canvas and the program reports it).
  • The clipboard: pasting an image (Windows). If the system clipboard is unavailable an internal copy is used.
  • A sprite sheet: File > Import sprite sheet, see Layers and Timeline.
  • AI image to pixel art: converting an image with grid recovery - page.
  • Aseprite: opening .aseprite files with layers, frames, animations and durations preserved.

The image file size is limited. Files that are too large or empty are rejected with the messages "Image file is empty or too large" or "Unsupported image or image dimensions".

Palettes

Importing palettes from PNG, HEX, GPL and JSON is described on the Palettes page.

The coordinate system when importing

Inside the program row 0 is the top row. Imported images go through a single row conversion at the boundary (so the head stays on top), and export does the reverse. If you build mods or external tools, follow the same rule.
