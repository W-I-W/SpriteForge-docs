AI image to pixel art

Turns a "pseudo-pixel" image (for example one made by a neural network) into real pixel art: it finds the source grid, aligns the blocks and reduces the palette. It works locally, with no network requests.

Open it through Filter > AI image to pixel art.... Load a PNG or JPG with the Load image... button.

Step 1. Pixel grid

  • Detect grid - automatically determines the "pixel" size and offset in the source. If the detection is uncertain the window warns you - check the alignment with the Adjust grid button.
  • Source pixel cell size (4 by default) - the cell size of the source image. 1 processes individual pixels; larger values align the blocks.
  • Grid offset X / Y - the grid shift.

Step 2. Appearance

Conversion style chooses how a block's color is obtained:

StyleIdea
Balanced blocksaverages each block for a clean, even result
Sharp edgestakes a pixel near the block center, keeping edges crisp
High contraststrengthens light and dark areas before limiting the palette
Dithered palettedistributes the color error between pixels (dithering) to keep smooth transitions with few colors
Dominant clustersuses the most common color group in a block: solid shapes and sharper boundaries
Posterized shadinggroups brightness into four bands - graphic, stepped shadows
Grayscaleshades of gray before limiting the palette
Handheld greenfour retro green tones by brightness
Soft pastellightens and softens saturation
Ink outlinesadds a dark one-pixel outline along strong color and silhouette edges
  • Maximum colors (2-256, 16 by default) - the size of the final palette.
  • Separate palette per tile - the palette is limited independently for each tile (Tile width, Tile height in pixels of the recovered grid, Show tile grid); the whole image may contain more colors.
  • Line thickness (0-4 px) - 0 keeps the original outline width, 1-4 set a uniform width in grid pixels.
  • Cleanup and extra settings: Noise reduction (0-100, removes isolated color noise before the palette is reduced), Pixel art cleanup (0 - off; higher merges close colors and cleans small silhouette defects), Transparency threshold.

Step 3. Result

  • The result size is shown as "Result: W x H | N colors" ("Source: W x H" is the source size).
  • Align without resizing - only align and limit the palette without shrinking the image.
  • Save PNG... - save the result.
  • Add to canvas as new frame - insert into the document as a new frame.
  • Create document - create a new document from the result.

Orientation rule: the result is inserted into the document with row 0 at the top. To be sure of this, test the conversion on an asymmetric image (head on top, feet at the bottom).
