Physics animation

The Physics animation window creates a sequence of frames from the current frame: falling, bouncing, stretching, "jelly" squashing and breaking.

How it works

  1. Draw or generate a sprite on the current frame ("Source: current frame N"). If the frame is empty the program reports: "The current frame has no painted pixels to animate".
  2. Open the Physics animation window and enter an animation name and the frame count. The frame count includes a copy of the current frame; a visible rebound needs at least 3 frames.
  3. Set the physics and press create. The new frames are added to the Timeline as an animation with that name ("Created N physics animation frames").

The timeline holds at most 120 frames. If there are fewer free slots than needed, the program warns you. A new animation needs at least 2 free frames.

Material

ParameterEffect
Elasticity (default 0.65)0 - stays at the edge; 1 - rebounds to the starting height after every impact. More frames allow more bounces. At a side wall low elasticity sticks and slides, high elasticity rebounds and can shatter the object on a strong hit.
Squishiness (0.45)0 - rigid; 1 - squashes and wobbles like jelly without breaking by itself.
Material strength (0.75)0 - breaks into pieces on impact; 1 - stays intact. The faster the fall, the more damage.
Damping (0.2)0 - the shape wobble lasts longer; 1 - it fades faster.

Motion

  • Gravity / fall speed (1-100, 12 by default); Gravity (px/s²) and the direction (Gravity direction): drag the arrow or choose a direction with the buttons. The higher the gravity, the sooner the sprite reaches the edge and the more bounces fit in the same number of frames.
  • Fall to canvas edge - the sprite falls to the canvas edge in the chosen direction.
  • Push - the initial push: drag from the center, the direction and distance set the impulse; the Horizontal impulse (px/s) and Upward impulse (px/s) fields; Clear push resets it.
  • Loop motion - the motion returns to the source pose at the cycle boundary.

Stretching and pinning

  • Stretch anchor - the point relative to which the deformation is formed; it moves with the sprite. Drag it on the sprite, click an edge to enable stretching toward that side.
  • Stretch sides and Stretch per side (px) - which sides stretch and by how much; the point stays fixed. The With falling and Without falling (No gravity) modes are configured separately; there are quick options "All except top / bottom".
  • Pinned point / Pin feet - the part of the sprite that must stay in place (for example the feet). Choose it with the Place point on canvas button and a click on the canvas; Finish point placement or Esc returns to painting. In point-selection mode drawing is disabled ("POINT MODE"). The Choose sides from point button picks the stretch sides from the point's position.

Preview

The Preview frame, Stop preview and Loop preview buttons show the result before the frames are created. The "How do these settings work?" block contains a short help for the parameters.
