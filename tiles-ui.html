Tiles and UI

Generators that create whole sets: 48 tiles for maps and interface components in four states.

Tiles

The Tiles generator creates a complete set of tiles for auto-tiling: an 8 x 6 map, that is 48 cells. The size of the set is determined automatically.

The Tiles mode is no longer selectable in the interface (the mode selector was removed). The generator still runs for documents or presets that were saved in the Tiles mode. For seamless tiles use Tile Repeat.

  • Use a square canvas ("Use a square canvas for the 48-tile generator").
  • The source drawing sets the colors and texture; the generator creates edges, corners and interior variants.
  • The Tileset output mode of the export window puts the frames onto one sheet.

UI components

The UI generator (the UI generation settings window, PIXEL UI COMPONENTS; turn it on with Apply UI to Drawing) creates "clean" component shells without icons or text.

ButtonPanelSlider

  • States: Normal, Hover, Pressed, Disabled. Each component is generated once per state ("Fixed state set"); identical parts of different states are shared.
  • UI kit / UI set - a set of assembled examples of all components; the output has all four states of each.
  • Generate separate UI parts - outputs each part as a separate cropped sprite ready for a UI Image. The preview shows the assembled component.
  • Appearance parameters: Button rounding, Window rounding, Handle size, Thumb width / height, Style (Flat, Beveled, Double frame, etc.), Accent.
  • For detailed components use a canvas of 64 x 64 pixels or larger.
  • Apply UI to Drawing - a checkbox at the top of the window: it turns on the UI generator instead of the plain Drawing variations.
  • 9-slice: together with the Slice tool you can define the center area for scalable UI.
