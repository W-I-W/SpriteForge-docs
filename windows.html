Window reference

All windows of the program: how to open them and what they are for. The identifiers are used by mods (SpriteForgeModApi.SetWindowVisible).

Working panels

WindowId for modsWhat it does
CanvascanvasThe canvas with rulers, grid and guides. Wheel - zoom (1x-64x), Ctrl+wheel - brush size (1-50). More.
ToolstoolsTen buttons for the tool families. Tools.
Tool settingstool-settings, palettesParameters of the active tool. The palette lives here: at the top are the swatches of the drawing palette (see Palettes), below them the Fill / Outline paint parameters and the generation colors. For the Mirror, Frame lighting and Noise fade area tools it shows their own settings.
PreviewpreviewA preview of the document or of a generation result (the source is picked from a list), the New example button.
TimelinetimelineLayers, frames, animations, playback. Layers and Timeline.
Generation toolbargeneration-toolbarNot a separate window: its controls sit in the tab bar of the Sprites window - the number of sprites/variants/states, the Generate button (magic wand) and the "Generate all frames per variant" toggle.
Sprites (Generated sprites)generated-spritesThe results of the last generation and the actions on them. Its tab bar holds the generation controls.
Result libraryresult-libraryThe permanent result library. Library.
LightinglightingLighting during generation and frame lighting. Frame lighting.
GuidesguidesRulers and guides.
History performancehistory-performanceHistory size and measurements. History.

Dialogs and helper windows

WindowHow to openWhat it does
New documentFile > New document (id new-document)Name, width and height (32 x 32 by default), common-size buttons. Shows the memory estimate "Estimated memory: X / Y MiB". Errors: an empty name, exceeding the texture size, exceeding the memory budget.
Import sprite sheetFile > Import sprite sheetSlicing a sheet into frames: cell size, margins, spacing, columns/rows, frame limit, FPS. Import.
Drop dialogDragging a file into the windowFor PNG, JPG or .aseprite: Create new document or Insert into current document (available when an editable document exists), or Cancel. Shows the image size.
Resize canvasEdit > Resize canvas... (id expand-canvas)New width and height, nine anchors. Canvas.
Replace colorEdit > Replace color in document (id replace-color)Replacing a color in all layers and frames.
Color limit / Color indexing / Inversion / Saturation / Gamma / OutlineThe Filter menu (ids color-limit, color-index, invert-colors)Filters. Filters.
Palette toolsFilter > Palette toolsRamps, Hue shift, Replace colors, Indexed, Palette swap.
AI image to pixel artFilter > AI image to pixel art... (id ai-pixel-art)Image conversion.
Export spritesFile > Export... (id export)Export.
PropertiesEdit > Properties... (id user-settings)Settings.
Unsaved changesClosing a document or exiting"Save changes to ...?": Save and close, Discard changes, Cancel.
Recover unfinished workOn start after a crash; File > Recover allRestoring documents from the autosave, Recovered / Failed counters, the Stop after this document button. Recovery.
