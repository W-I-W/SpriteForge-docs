FAQ

Common situations and their solutions.

Drawing

The tool does not draw

Check whether a document is open, whether the active layer is hidden or locked, and whether an active selection does not include the cursor. If point-selection mode is on (Physics animation, "POINT MODE") the canvas does not draw - press Esc or Finish point placement.

The pencil line is "stair-stepped"

Turn on Pixel-perfect in the pencil settings (it works with a 1 px brush).

How to take a color from the canvas

Press I or hold Ctrl. The picker also takes the Body/Outline properties.

How to draw a seamless texture

Turn on Tile Repeat. The drawing will wrap around the borders.

Animation

I cannot add a frame

A document holds at most 120 frames. Free up slots or check the memory budget.

The animation does not play

Press Space while the Timeline has focus, or select a tag bar above the layers and press Play. Make sure the range contains at least two frames.

How to give frames different speeds

Set the Frame duration (ms) of each frame; 0 means the common FPS. The durations are saved in .sf, in the PNG metadata and in the GIF.

Generation

The generator gives the same result

Turn off the fixed seed: turn on Random seed or change the Seed.

The result does not fit the canvas

Large sprites are cropped around the center or fitted (when inserting as a frame). Enlarge the canvas with C or Resize canvas.

Where is the 48-tile generator?

It is no longer offered in the interface; use Tile Repeat for seamless tiles. A document or preset saved in the Tiles mode still runs it, and it needs a square canvas.

Files

I saved a PNG but the project is not saved

That is expected: exporting does not replace saving. Press Ctrl+S for the .sf.

The program crashed - is my unsaved work gone?

On the next launch choose Recover unfinished work. More: Recovery.

The CSS export refuses

The limit is one million visible pixels. Export a PNG.

"Project memory budget exceeded"

The estimated 1 GiB budget is used up. Reduce the canvas size, the number of layers or frames, or close extra documents.

Interface

The interface is too small or too large

The scale is changed with Ctrl++ / Ctrl+-; Ctrl+Shift+0 picks it automatically. The same parameter is Interface scale in Properties.

F1 says "Documentation not found"

The program looks for a docs folder next to itself (in the editor - in the project root). Put this documentation there.

Where did the learning game go?

It was replaced by a short Quick tour (Help > Quick tour).

I cannot find a mode selector for Effects, Furniture, UI and Character

They are add-ons over Drawing: open the settings window of the needed generator and turn on the "Apply ... to Drawing" checkbox. See Generators.

Where is Auto noise?

It is added from the Auto generator window.

What happened to "Generator mirror"?

Mirroring during generation is now turned on with the During generation icon in the Mirror settings and uses the same axes as drawing.

I lost a panel

View > the window name, or View > Reset panel layout.

How to change the language or theme

Edit > Properties: the Language and Appearance tabs. More: Settings.
