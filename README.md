# SpriteForge - documentation

Documentation for the SpriteForge pixel art editor: tools, windows, generators, animation, export and mods.

- English (default): the site root, `index.html`
- Russian: `ru/index.html`

Site: https://w-i-w.github.io/SpriteForge-docs/ (Russian: https://w-i-w.github.io/SpriteForge-docs/ru/)

This is a static site with no build step: open `index.html` in a browser, or publish the repository root with GitHub Pages (Settings - Pages - Deploy from a branch - `main` / `(root)`).

If these files are placed in a `docs` folder next to the program, `Help > Documentation` (`F1`) opens them in the browser.
