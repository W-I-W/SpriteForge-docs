# SpriteForge - документация

Документация редактора пиксель-арта SpriteForge: инструменты, окна, генераторы, анимация, экспорт, моды.

Сайт: https://<ваш-логин>.github.io/<имя-репозитория>/

Это статический сайт без сборки: откройте `index.html` в браузере или опубликуйте папку через GitHub Pages (Settings - Pages - Deploy from a branch - `main` / `(root)`).

Если положить эти файлы в папку `docs` рядом с программой, пункт `Help > Documentation` (`F1`) откроет их в браузере.
