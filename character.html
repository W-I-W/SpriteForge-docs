Character generator

The Character settings window (PIXEL CHARACTER GENERATOR) assembles a pixel character from parts and creates a set of animations with directions.

Open Character settings and turn on Apply character to Drawing. An open document is required.

The Apply character to Drawing checkbox at the top of the window turns on the character generator instead of the plain variations of your drawing.

Presets and a random character

  • Character preset / Apply character preset replaces the body, clothing, equipment and colors with a ready-made template. Presets include Adventurer, Knight, Mage, Rogue, Cleric, Barbarian, Worker, Office worker, Student, Athlete, as well as creatures - Skeleton, Zombie, Vampire, Orc, Goblin, Troll, Ogre, Demon and others. After applying, refine the other sections.
  • Random character builds a random person, animal or monster. The same seed always gives the same character.

Settings sections

SectionParameters
BasicsGame view (the view: Platformer, Top down, etc.), Sprite size / Sprite dimensions, Pixel block size (larger blocks give a coarser look), Size within sprite (how much of the canvas the character fills), Ground shadow (a soft semi-transparent shadow under the feet).
Body & proportionsBody build (Slim, Average, Athletic, Stocky, Bodybuilder, Custom), height, width, body depth, head (Head width / height), Shoulder width, Waist width, Hip width, Belly size, Arm length / thickness, Leg length / thickness, Muscle definition. Editing the shape switches the build to Custom.
SpeciesHuman and animals: Fox, Wolf, Bear, Cat, Rabbit, Deer, Boar, Dog - in two variants (upright and "four legs"). Parameters: Body length, Ear size, Snout length, Tail size. Colors: Skin - fur, Fur - muzzle, belly and tail tip. Four-legged animals do not wear clothes; to dress them turn off "Walks on four legs".
HairHair style (Bald, Short hair, Long hair, Bob, Bun, Ponytail, Braids, Mohawk, Spiky, etc.), Hair length, Hair volume, Parting, Tail / bun size; the parameters depend on the selected style.
ClothingTop (Shirt, Tank top, Hoodie, Jacket, Coat, Robe, Shirtless), bottoms (Pants, Shorts, Leggings), footwear (Shoes, Boots, Bare feet), Sleeve length, Hem length. Shirt and pants colors can be taken from the current palette.
EquipmentHeadgear (Hood, Circlet, Wizard hat, Horned helmet, Open helmet, Great helm; None removes the item), Weapon (Sword, Dagger, Axe, Spear, Staff), Shield (Round shield, Kite shield), Armor, Cape (Cape length, Cape color, Fringe length), Belt and buckle; item sizes (Weapon size, Headgear size).
ColorsSkin, Trim / accent, Cape color, etc.; Use palette for fill / outline / clothes - take colors from the palette; Outline follows body.
AnimationsChoosing the animations to create and the playback speed (Movement strength, Playback speed). Playback speed also controls the live preview.
Directions to generateDefault direction and the set of directions: Down, Up, Left, Right, diagonals and "All eight". The more animations and directions, the more frames.

The Generate character button creates the sprites. The results appear in the "Generated animations" window: each variant can be saved as a separate GIF, its frames added to the document (Insert all animation frames on the active layer) or saved to the library.

The live preview in the settings window is built from the current values (Live example from current settings), so you can see the result before generating.
