Export

The Export sprites window (File > Export...) exports a document or generated animations to various formats.

Window buttons

  • Choose location and export - opens a save dialog and exports the chosen data in the chosen format.
  • Cancel - closes the window without exporting.

Source

The source dropdown chooses what to export: the document's frames or (when available) generated animations. For a document two selection modes are available:

  • Selected animation - a named animation (its layers, durations and loop setting).
  • Frame range - a range of frames: First frame and Last frame (numbered from 1).

Frame and clip indices in the JSON are recalculated relative to the exported sequence. The same selection applies to PNG, tileset, GIF and CSS.

Engine atlas

  • Unity (JSON) - an atlas with Pixels per unit.
  • Godot (JSON + SpriteFrames .tres) - a SpriteFrames resource is additionally created; the Godot resource folder field sets the resource path inside the project.
  • Phaser (JSON atlas with tags) - a JSON atlas with tags.

.aseprite

The export contains layers, frames, tags and durations. Groups are flattened and layer masks are not saved. Importing .aseprite is also supported - see Projects and import.

Limits and errors

  • The file name must not contain invalid characters.
  • "Output is too large. Reduce scale" - the final image is too large; reduce Pixel scale or change the number of columns.
  • For a tileset and GIF all sprites must have the same size ("All sprites must have the same dimensions").
  • Writes are transactional: if something fails an existing file is not lost.

Exporting a PNG/JPEG does not replace saving the project: save the .sf so you do not lose layers and tags.

Exporting individual parts

  • A slice - the Export PNG button in the settings of the Slice tool.
  • A generation result - Save sprite as PNG / Save animation as GIF in Generated sprites.
  • The library - PNG export from the Result library.
  • Pencil styles - JSON or a transparent PNG (at most 32 x 32).
