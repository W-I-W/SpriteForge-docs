Выделение и преобразование

Пять инструментов выделения, общие режимы комбинирования и рамка преобразования.

Инструменты выделения

Rectangular marquee (M), Elliptical marquee (Shift+M), Lasso (Q), Polygonal lasso (Shift+Q) и Magic wand (W). Описание каждого - на странице Инструменты.

Меню Select

  • Select all (Ctrl+A) - выделить весь холст.
  • Select opaque pixels - выделить все непрозрачные пиксели активного слоя и кадра.
  • Invert selection - инвертировать.
  • Deselect (Ctrl+D).
  • Expand / Shrink - расширить или сузить выделение на значение Amount (px) (по умолчанию 1).
  • Magic Wand - флажок Contiguous и ползунок Tolerance.

Если выбран флажок Select all layers, преобразование и удаление выделенных пикселей применяется ко всем видимым незаблокированным слоям текущего кадра. В противном случае - только к активному слою.

Что можно делать с выделением

  • Переместить - перетащите внутри выделения, либо используйте инструмент Move (V). Esc отменяет перетаскивание.
  • Удалить пиксели - Delete.
  • Копировать / вставить - Ctrl+C / Ctrl+V (Edit > Copy selection / Paste selection). Если системный буфер изображений недоступен, копия остаётся внутри SpriteForge.
  • Повернуть на 90 градусов, отразить по горизонтали / вертикали - команды меню Edit.
  • Ограничить рисование - любые инструменты рисования работают только внутри выделения. Индикатор «Selection active» и кнопка Deselect pixels показываются в Tool settings.
  • Стать штампом - Pencil → Copy selection to pencil (область не больше 32 x 32).

Рамка преобразования

При выборе выделения вокруг него появляется рамка с маркерами:

  • Квадраты - изменение размера.
  • Круг - поворот. Ctrl привязывает направление и угол к шагу 45 градусов.
  • Синий и зелёный ромбы - симметричный наклон (skew) вокруг центра по осям повёрнутого изображения.
  • Фиолетовые углы - независимое искажение (distort): каждый угол двигается отдельно. Esc восстанавливает предыдущую форму.
  • Внутри рамки - перемещение.

Во время перетаскивания подсказка показывает величину наклона в пикселях. Результат растеризуется на сетку пикселей.
